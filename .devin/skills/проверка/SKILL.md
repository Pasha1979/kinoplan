Выполни UI-проверку KinoPlan (read-only, код не менять):

1. **Dev-сервер**: проверь, отвечает ли http://localhost:5173. Если нет — запусти `npm run dev` в фоне и запомни shell_id (свой — останови в конце; чужой — не трогай).
2. **Готовность**: жди ответа 200 на :5173 (до 60 с). Не ответил — стоп, покажи лог.
3. **Playwright MCP** (`browser_navigate`, `browser_snapshot`, `browser_take_screenshot`, `browser_console_messages`):
   - открой http://localhost:5173, дождись окончания сплэша (~3 с, «Создать первый проект» или список проектов виден; `browser_evaluate` с setTimeout 3000);
   - проверь: h1/логотип «КиноПлан»; шапка (banner) с кнопками «Импорт проекта», тема, «Помощь (F1)»; главная кнопка («Создать первый проект» либо список проектов); футер (`footer`/`contentinfo`) — если нет, пометь ⚠️ «футера нет»;
   - скриншот → `_ai_workspace/v4/screens/проверка-<дата>.png`;
   - `browser_console_messages` уровня `warning` (all=true) — собери ошибки и предупреждения.
4. **Отчёт** таблицей: проверка → статус (✅/⚠️/❌) → доказательство; ниже список console error/warning дословно.
5. **Финиш**: `browser_close`; останови dev-сервер, если запускал сам. Ничего не коммить.

Правила: русский язык, скоуп — только проверка, найденные баги не чинить без запроса (записать через `npm run brain:add`, если пользователь попросит).
