### P0 — Критично улучшения UX:

#### 1. Прогресс на карточках проектов — ✅ РЕАЛИЗОВАНО (31.10.2026)
- Показать прогресс-бар на каждой карточке проекта

- Визуально сразу видно, над чем работать
- Источник данных: количество сцен в сценарии, статус сцен

#### 2. Последние проекты (Recently Opened) — ✅ РЕАЛИЗОВАНО (31.10.2026, вкладка «Недавние»)
- Показать 3-4 недавно открывавшихся проекта сверху
- С иконкой "часы" или "недавно"
- Быстрый доступ к активным проектам
- Сортировка по времени последнего открытия

#### 3. Избранное (Favorites) — ✅ РЕАЛИЗОВАНО (31.10.2026, звёздочка + вкладка + всегда сверху)
- Звёздочка на карточке проекта
- Избранные проекты всегда сверху
- Быстрый доступ к важным проектам
- Сохранять избранное в localStorage

#### 4. Сортировка и фильтры — ✅ РЕАЛИЗОВАНО (31.10.2026, FilterDropdown + сброс)
- Сортировка: по дате, по названию, по прогрессу
- Фильтр по типу: Фильм / Сериал / Реклама / Клип
- Фильтр по статусу: Preproduction / Production / Postproduction
- UI: дропдаун с опциями сортировки и фильтрации

## � Заметки для реализации:

**Порядок реализации:**
1. Сначала P0 (прогресс, последние, избранное, сортировка/фильтры)
2. Потом P1 (быстрые действия, активность)
3. Потом P2 (теги, drag-and-drop, контекстное меню, список дел, мини-календарь)

**Технические требования:**
- Прогресс: нужно интегрироваться с данными сценариев
- Последние проекты: добавить поле `lastOpenedAt` в Project
- Избранное: добавить поле `isFavorite` в Project
- Сортировка/фильтры: UI компоненты в HomePage
- Теги: добавить поле `tags` в Project (массив строк)
- Drag-and-drop: использовать @dnd-kit (уже есть в проекте)

**Хранилище:**
- Использовать existing `projectStore` / `projectService`
- Новые поля в `Project` type
- Сохранение в localStorage (текущее хранилище)
