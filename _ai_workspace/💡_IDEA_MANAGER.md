# 💡 IDEA MANAGER — Система управления идеями

> **Назначение:** Запоминание, анализ, систематизация и напоминание идей пользователя

---

## 🎯 ПРИНЦИП

Все идеи пользователя запоминаются, анализируются в контексте видения, но реализуются ТОЛЬКО по команде.

---

## 📚 РАБОТА С ИДЕЯМИ

### При появлении идеи:
1. **Записать идею** в `💡_ЗАДЕЛЫ_ИДЕИ.md`
2. **Проанализировать идею** в контексте видения
3. **Предложить улучшения** идеи
4. **Определить приоритет** реализации
5. **Обновить план** если идея меняет стратегию
6. **Сообщить пользователю** что идея записана

### При изменении видения:
1. **Проверить все идеи** на актуальность
2. **Устаревшие идеи** → архивировать
3. **Актуальные идеи** → предложить реализацию
4. **Обновить план** если нужно

### При переключении задач:
1. **Напомнить о незавершённых идеях**
2. **Предложить вернуться к незавершённой**
3. **Обновить приоритеты** если нужно

---

## 🔍 АНАЛИЗ ИДЕИ

### Контекстный анализ:
- Соответствует ли идея видению приложения?
- Улучшает ли идея существующий функционал?
- Нужна ли идея сейчас или позже?
- Блокирует ли идея другие задачи?

### Предложение улучшений:
- Как можно сделать идею лучше?
- Есть ли альтернативные решения?
- Какой ROI у идеи?

## 📋 СТАТУСЫ ИДЕЙ

| Статус | Значение |
|--------|----------|
| 🔥 Новая | Только что предложена |
| 💭 На анализе | Изучается feasibility |
| 📅 В план | Запланирована в ПЛАН_РАБОТ.md |
| 🚀 В работе | Реализуется (по команде) |
| ⏸️ Приостановлена | Реализована частично, приостановлена |
| ✅ Реализована | Полностью реализована |
| 🧊 Отложена | Интересно, но не приоритетно |
| ❌ Отклонена | Не соответствует видению |
- 📝 Анализировать идею в контексте видения
- 💡 Предложить улучшения идеи
- 📊 Определить приоритет
- 🔄 Обновить план если нужно
- 📞 Сообщить пользователю: "Идея записана: [краткое описание], приоритет: [P0/P1/P2]"

## 🔔 НАПОМИНАНИЯ

### Еженедельное напоминание:
```
🔔 НАПОМИНАНИЕ: Незавершённые идеи

У вас есть незавершённые идеи:
- [Идея 1] — [статус]
- [Идея 2] — [статус]

Хотите вернуться к одной из них?
```

### При переключении задачи:
```
🔔 НАПОМИНАНИЕ: Приостановленная идея

Вы работали над [Идея], но приостановили.
Хотите вернуться к ней?
```
