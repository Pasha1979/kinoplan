# 🧠 SESSION CONTEXT — Автоматическое сохранение контекста сессии

> **Назначение:** Автоматическое сохранение текущего контекста для восстановления после лимита токенов
> 
> **Правило:** Контекст обновляется автоматически перед каждым значительным действием

---

## 🔄 АВТОМАТИЧЕСКИЙ WORKFLOW

### 📸 Когда сохранять контекст (автоматически):
- Перед началом новой задачи
- После завершения задачи
- После каждого коммита
- При изменении фокуса работы
- При достижении лимита токенов (текущее действие)

### 📖 Когда восстанавливать контекст (автоматически):
- В начале каждой сессии (после очистки контекста)
- Если обнаружено что контекст потерян

### 🗑️ Когда архивировать старый контекст:
- Когда начинается новая сессия с новым фокусом
- Когда прошло более 1 дня с последнего обновления

## 🔒 ПРАВИЛА ОБНОВЛЕНИЯ

### Перед обновлением:
1. Проверить дату последнего обновления
2. Если старый контекст (более 1 дня) → архивировать в _archive/
3. Если новый фокус работы → создать новый файл

### При обновлении:
1. Перезаписать весь файл
2. Обновить дату и время
3. Обновить фокус и статус
4. Сохранить в git
