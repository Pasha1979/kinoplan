### 💡 КЛЮЧЕВЫЕ ИНСАЙТЫ ДЛЯ КИНОПЛАНА

**Что взять от Final Draft:**
1. **Revision Mode** — цветные ревизии, блокировка страниц (критично для продакшена)
2. **Tagging for Production** — теги для реквизита, костюмов (связь с Breakdown)
3. **Real-time Collaboration** — совместная работа сценаристов
4. **Track Changes** — отслеживание изменений для обсуждения

**Что взять от КИТ Сценарист:**
1. **Раздел Разработка** — персонажи, локации, материалы в одном месте
2. **Статистика с графиками** — динамика персонажей, хронометраж
3. **Модуль карточек** — визуальная структура истории
4. **Российский формат** — поддержка отечественных стандартов

**Уникальное преимущество КиноПлана:**
- **Единая экосистема** — сценарист пишет → 2-й режиссёр видит изменения → Breakdown автоматически обновляется
- **Интеграция с планированием** — сцены из сценария → Stripboard → Вызывные листы
- **Версионность с диффом** — видно что изменилось между версиями
- **Уведомления группы** — вся команда видит обновления сценария
