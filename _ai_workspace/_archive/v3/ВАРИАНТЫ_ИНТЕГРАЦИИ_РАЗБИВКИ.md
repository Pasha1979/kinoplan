## ВАРИАНТ А — Авто-разбор текста (Auto-Parse)

### Что делает
При переключении на вкладку РАЗБИВКА — автоматически парсит текст сценария и выделяет элементы.

### Как работает
1. **Персонажи** — слова в КАПСЛОКЕ перед диалогами
   - ИВАН → Актёр
   - МАША → Актёр
   
2. **Локации** — текст после ИНТ./ЭКСТ.
   - «ИНТ. КВАРТИРА ИВАНА — ДЕНЬ» → Локация: КВАРТИРА ИВАНА
   
3. **Реквизит** — ключевые слова в action-блоках
   - «Иван берёт ПИСТОЛЕТ» → Реквизит: ПИСТОЛЕТ
   - «звонит ТЕЛЕФОН» → Реквизит: ТЕЛЕФОН
   - «садится в МАШИНУ» → Транспорт: МАШИНА

### Преимущества для сценариста
- ✅ Не нужно вручную заполнять — всё само собирается
- ✅ Видит полную картину персонажей и локаций
- ✅ Контроль: не забыл ли я про пистолет из сцены 3?

### Недостатки
- ❌ Может ошибаться (двусмысленности)
- ❌ Требует ручной корректировки
- ❌ Не даёт аналитики, только списки

## ВАРИАНТ Б — Статистика и Аналитика (Script Analytics)

### Что делает
Вкладка РАЗБИВКА показывает аналитику по сценарию — не просто списки, а insights.

### Вкладки внутри РАЗБИВКИ

#### 1. «Баланс персонажей»
- Сколько сцен у каждого героя
- Сколько страниц диалога
- График: появление персонажей по сценам
- ⚠️ Алерт: «Персонаж ИВАН пропал на 15 страницах (сцены 8-12)»

#### 2. «Хронометраж»
- Расчётное время каждой сцены
- Общий хронометраж по актам
- ⚠️ Алерт: «Сцена 23 — 4.5 минуты, рекомендуется 2-3 минуты»

#### 3. «Динамика»
- Соотношение Диалог / Действие по сценам
- График: динамика темпа
- ⚠️ Алерт: «3 сцены подряд только диалог — добавить действие?»

#### 4. «Структура»
- Распределение по актам (акт 1, акт 2, акт 3)
- Контрольные точки сюжета
- Сравнение с классической структурой (Save the Cat)

### Преимущества для сценариста
- ✅ Понимает структуру сценария
- ✅ Видит слабые места (длинные сцены, пропавшие персонажи)
- ✅ Контроль темпа и баланса
- ✅ Соответствие индустриальным стандартам

### Недостатки
- ❌ Не помогает при написании, только анализ готового
- ❌ Может быть перегружено данными

## ВАРИАНТ В — Помощь в процессе написания (Smart Assistant)

### Что делает
Активно помогает ПРИ НАПИСАНИИ, не только после.

### Функции

#### 1. SmartType (автодополнение)
- При вводе «ИВ...» — подсказка «ИВАН (введён в сцене 1)»
- При вводе локации — подсказка из уже использованных
- Tab для автодополнения

#### 2. Контекстные подсказки
- При создании сцены 10: «В сцене 5 Иван получил пистолет. Добавить сюда?»
- При вводе диалога: «Иван не появлялся 8 страниц. Напомнить читателю кто он?»

#### 3. Проверка непрерывности
- «В сцене 3 было ночь, а здесь день. Указать прошло время?»
- «Локация изменилась без перехода. Добавить CUT TO?»

#### 4. Голосовой набор
- Говоришь — текст превращается в форматированный сценарий
- «Сцена первая, интерьер, квартира Ивана, день...» → 1. ИНТ. КВАРТИРА ИВАНА — ДЕНЬ

### Преимущества для сценариста
- ✅ Ускоряет набор (SmartType)
- ✅ Снижает ошибки непрерывности
- ✅ Помогает помнить детали
- ✅ Можно писать голосом

### Недостатки
- ❌ Требует постоянной работы ИИ
- ❌ Может раздражать навязчивыми подсказками
- ❌ Сложнее в реализации

## ЛУЧШИЙ ВАРИАНТ — КОМБИНАЦИЯ A + B + V

### Архитектура: 3 режима работы

```
┌─────────────────────────────────────────────────────────┐
│                    РАЗБИВКА / АНАЛИТИКА                  │
├─────────────────────────────────────────────────────────┤
│  [Авто]  [Статистика]  [Помощник]  [Ручной ввод]       │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  РЕЖИМ 1: АВТО (Вариант А)                              │
│  ├── Парсинг текста → автозаполнение категорий          │
│  ├── Редактирование вручную                            │
│  └── Синхронизация с текстом (при изменении → обновить) │
│                                                         │
│  РЕЖИМ 2: СТАТИСТИКА (Вариант Б)                       │
│  ├── Дашборд с метриками                               │
│  ├── Алерты по структуре                               │
│  └── Рекомендации (откуда Final Draft)                 │
│                                                         │
│  РЕЖИМ 3: ПОМОЩНИК (Вариант В)                         │
│  ├── SmartType в редакторе                             │
│  ├── Подсказки при наборе                              │
│  └── Проверка непрерывности                            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### Уникальные фишки (нет у конкурентов)

1. **Сценарный дашборд в реальном времени**
   - Пока пишешь — видишь метрики (как GitHub contributions)
   - Цветовая индикация: зелёный (хорошо), жёлтый (внимание), красный (проблема)

2. **Сравнение версий**
   - Черновик 1 vs Черновик 2: что изменилось в разбивке
   - «+2 новых персонажа, -1 локация, хронометраж +5 минут»

3. **Рекомендации от AI**
   - «У вас 12 персонажей — много для короткометражки, рекомендуется 3-5»
   - «Соотношение диалог/действие 70/30 — для триллера лучше 50/50»

4. **Интеграция с кастингом**
   - Нажал на актёра → видишь все его сцены
   - Кнопка «Создать выборку для актёра» (для репетиций)

## ПЛАН РЕАЛИЗАЦИИ ЛУЧШЕГО ВАРИАНТА

### Фаза 1: Авто-парсинг (Вариант А)
- Парсер для персонажей (КАПСЛОК перед диалогом)
- Парсер для локаций (ИНТ./ЭКСТ.)
- Парсер для реквизита (ключевые слова)
- UI: список с ручным редактированием
- Синхронизация при изменении текста

### Фаза 2: Статистика (Вариант Б)
- Подсчёт сцен на персонажа
- Подсчёт страниц диалога
- Хронометраж по сценам
- Алерты (пропавшие персонажи, длинные сцены)
- Графики динамики

### Фаза 3: Помощник (Вариант В)
- SmartType (автодополнение)
- Подсказки контекста
- Проверка непрерывности
- Голосовой набор (опционально)
