## ОТЛИЧИЯ ОТ ГОЛЛИВУДСКОГО ФОРМАТА

| Элемент | Российский формат | Голливудский формат |
|---------|------------------|---------------------|
| **Заголовок сцены** | `1. ИНТ. КУХНЯ — ДЕНЬ` | `INT. KITCHEN - DAY` |
| **Номер сцены** | **Да** (1., 2., 3.) в начале | Нет (добавляется позже) |
| **ИНТ./ЭКСТ.** | ИНТ. / ЭКСТ. (кириллица) | INT. / EXT. (латиница) |
| **Разделитель** | `—` (тире) | `-` (дефис) |
| **Время** | ДЕНЬ / НОЧЬ / УТРО / ВЕЧЕР | DAY / NIGHT / MORNING / EVENING |
| **Персонаж** | КАПСЛОК, по центру | КАПСЛОК, по центру |
| **Диалог** | Отступ слева (~5-6 см) | Отступ слева |
| **Ремарка** | В скобках перед диалогом | В скобках |
| **Переход** | КАПСЛОК, по правому краю | КАПСЛОК, по правому краю |

## РЕАЛИЗАЦИЯ В КИНОПЛАН (обновлено 31.05.2026)

### CSS-переменные для форматов

В `src/index.css` реализована система CSS-переменных для переключения между форматами:

```css
/* Russian format (KIT Scenarist standard) */
--russian-character-indent: 6.75cm;
--russian-dialog-left-indent: 3.75cm;
--russian-dialog-right-indent: 3.75cm;

/* Hollywood format (US industry standard) */
--hollywood-character-indent: 9.3cm; /* 3.7" */
--hollywood-dialog-left-indent: 6.35cm; /* 2.5" */
--hollywood-dialog-right-indent: 2.5cm;
```

Переключение через класс `.format-russian` или `.format-hollywood`

### Типы блоков Tiptap

1. **sceneHeader** — Шапка сцены: `2-1. ИНТ. КВАРТИРА ВЛАДЫ.КОМНАТА. НОЧЬ`
2. **sceneCast** — Список действующих лиц: `ВЛАДА, СВЕТА, РЯБИНИНА, ХАН`
3. **sceneAction** — Описание действия: `Влада лежит на кровати...`
4. **sceneCharacter** — Имя персонажа (диалог): `ВЛАДА`
5. **sceneDialog** — Реплика персонажа: `Как же мне плохо...`
6. **sceneTransition** — Переход: `РАССВЕТ`

### Автоматические переходы при Enter

| Текущий блок | Создаётся следующий |
|--------------|---------------------|
| sceneHeader | sceneCast (список персонажей) |
| sceneCast | sceneAction (описание) |
| sceneCharacter | sceneDialog (реплика) |
| sceneDialog | sceneAction |

### Отступы (Russian format)

| Элемент | Отступ | Пояснение |
|---------|--------|-----------|
| Шапка | 0 | Без отступа, КАПСЛОК |
| Список персонажей | 0 | Под шапкой, КАПСЛОК |
| Описание | 0 | Без отступа |
| Имя персонажа | 6.75cm | Центрировано |
| Диалог | 3.75cm слева, 3.75cm справа | Блок по центру |
| Переход | 0 | По правому краю, КАПСЛОК |

### Отступы (Hollywood format)

| Элемент | Отступ | Пояснение |
|---------|--------|-----------|
| Character name | 9.3cm (3.7") | From left page edge |
| Dialogue | 6.35cm (2.5") left | From left page edge |

### 2. Автонумерация сцен

**При выборе российского формата:**
- Автоматически добавлять номер сцены при создании нового заголовка
- Нумерация: 1, 2, 3... (последовательно)
- При удалении сцены — перенумеровать все сцены после неё
- При вставке сцены между — перенумеровать все сцены после

### 3. Форматирование в редакторе

**Заголовок сцены:**
- Отступ слева: 2-3 см
- Шрифт: обычный, не жирный
- Номер сцены: обычный шрифт, не жирный
- ИНТ./ЭКСТ.: КАПСЛОК
- Локация: обычный шрифт
- Тире: `—` (mdash)
- Время: КАПСЛОК

**Персонаж:**
- КАПСЛОК
- По центру или с большим отступом (~4-5 см)

**Диалог:**
- Отступ слева: 5-6 см
- Ширина: ~8-10 см

**Ремарка:**
- В скобках: `(раздумчиво)`
- В строке диалога или отдельной строкой

**Переход:**
- КАПСЛОК
- По правому краю

### 4. Переключатель форматов

**В настройках сценария:**
```
Формат сценария:
○ Голливудский (Hollywood)
● Российский (Russian)
```

**При переключении:**
- Если российский → добавить номера сцен
- Если голливудский → убрать номера сцен
- Заменить INT./EXT. на ИНТ./ЭКСТ. и наоборот
- Заменить DAY/NIGHT на ДЕНЬ/НОЧЬ и наоборот

### 5. Экспорт

**Формат экспорта при российском стандарте:**
- PDF с российским форматированием
- FDX (Final Draft) — конвертация в голливудский формат
- DOCX — сохранение форматирования

```
IRINA

CUT TO:
```
