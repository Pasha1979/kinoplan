# 📊 CONTEXT LIMIT TRACKER — Автоматическое отслеживание лимита контекста

> **Назначение:** Автоматическое определение приближения к лимиту контекста и сохранение истории диалога

---

## 🎯 ЛИМИТ КОНТЕКСТА

**Лимит:** 158,000 токенов
**Порог предупреждения:** 140,000 токенов (88%)
**Порог критический:** 150,000 токенов (95%)

---

## 📈 КАК ОПРЕДЕЛИТЬ РАЗМЕР КОНТЕКСТА

### Признаки приближения к лимиту:
1. **История диалога длинная** — много сообщений
2. **Появляется сообщение "context near limit"** — системное предупреждение
3. **AI начинает забывать ранние сообщения** — потеря контекста
4. **Ответы становятся короче** — экономия токенов

### Автоматическая проверка:
```markdown
После каждого действия:
1. Оценить длину истории диалога
2. Если > 140k токенов → СРОЧНОЕ СОХРАНЕНИЕ
3. Если > 150k токенов → НЕМЕДЛЕННОЕ СОХРАНЕНИЕ
```

---

## 💾 АВТОМАТИЧЕСКОЕ СОХРАНЕНИЕ ИСТОРИИ

### Что сохранять:
1. **Полная история диалога** — все сообщения
2. **Текущий контекст** — состояние проекта
3. **Активные файлы** — какие файлы редактируются
4. **Коммиты** — хэши и сообщения
5. **Vercel статус** — последний деплой

### Куда сохранять:
- `🧠_SESSION_CONTEXT.md` — текущий контекст
- `📝_DIALOG_HISTORY.md` — полная история диалога

### Когда сохранять (автоматически):
- При достижении 140k токенов
- При достижении 150k токенов
- При завершении задачи
- При коммите

---

## 🔄 АВТОМАТИЧЕСКОЕ ВОССТАНОВЛЕНИЕ

### При новой сессии (после очистки контекста):
1. **Прочитать 🧠_SESSION_CONTEXT.md** — текущий контекст
2. **Прочитать 📝_DIALOG_HISTORY.md** — история диалога
3. **Прочитать .env** — токен
4. **Восстановить:**
   - Что обсуждали
   - Что сделали
   - Что планировали
   - Текущее состояние
5. **Сообщить:** "Контекст полностью восстановлен из истории диалога"
