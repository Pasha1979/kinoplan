### 1. СТРУКТУРА МОДУЛЯ «СЦЕНАРИЙ» — Гибрид А+

**Решение:** Используем гибридный подход — вкладки внутри модуля + быстрые ссылки в сайдбаре

```
САЙДБАР                    ВНУТРИ МОДУЛЯ «СЦЕНАРИЙ»
├── 🏠 Дашборд             ┌─────────────────────────────────────────┐
├── 📝 СЦЕНАРИЙ      →     │  ТЕКСТ  │  КАРТОЧКИ  │  РАЗРАБОТКА  │📊│
├── 👥 Персонажи     →     ├─────────────────────────────────────────┤
├── 🏢 Локации       →     │                                         │
├── 📊 Статистика    →     │  [Контент активной вкладки]            │
└── 🎬 Продакшен    →     │                                         │
                           └─────────────────────────────────────────┘
```

**Обоснование:**
- Контекст сценария сохраняется (вкладки)
- Быстрый доступ к персонажам/локациям из сайдбара
- Масштабируемость без перегрузки интерфейса
- Близко к привычному КИТ Сценарист

### 2. АВТО-ФОРМАТИРОВАНИЕ — Гибридный подход

**Решение:** Объединяем умное распознавание + ручное управление Tab/Enter

#### Умное распознавание (по умолчанию):
| Что пишет пользователь | Распознаётся как |
|------------------------|------------------|
| `ИНТ.` / `ЭКСТ.` / `ИНТ./ЭКСТ.` | Заголовок сцены |
| `НАПЛЫВ:` / `СМЕНА ПЛАНА:` | Переход |
| ВСЕ ЗАГЛАВНЫЕ (2+ слова) | Имя персонажа |
| Обычный текст после имени | Диалог |
| Текст в скобках `(взволнованно)` | Ремарка в диалоге |
| Текст без заглавных | Описание действия (ремарка) |

#### Ручное управление (Tab/Enter):
- **Tab** — переключить тип текущего абзаца циклически:
  `Заголовок → Ремарка → Персонаж → Диалог → Проходка → Ремарка`
- **Enter** в конце диалога → автоматически переход к ремарке (готовность к следующей сцене)
- **Ctrl+1..6** — быстрое переключение типа абзаца по номеру

### 3. КАРТОЧКИ ДЛЯ СТРУКТУРЫ

**Решение:** Реализуем модуль карточек как в КИТ Сценарист

**Функционал:**
- Визуальная доска с карточками сцен
- Раскраска по актам / цветам
- Перетаскивание (drag & drop) для изменения порядка
- Синхронизация с текстом сценария
- Группировка по актам / последовательностям
- Печать карточек на бумаге

---

### 4. РАЗДЕЛ «РАЗРАБОТКА» — Полный состав

**Решение:** Включаем все элементы + дополнительные фичи

#### Базовые элементы (от КИТ Сценарист):
1. **Персонажи**
   - Имя, возраст, описание внешности
   - Биография, цели, арки
   - Материалы (фото, референсы, актёры)
   - Связи с другими персонажами (граф связей)

2. **Локации**
   - Название, тип (интерьер/экстерьер)
   - Описание, особенности
   - Материалы (фото, планировки)
   - Реальные адреса (для съёмок)

3. **Мир**
   - Лонглайн (1-2 страницы)
   - Синопсис (5-10 страниц)
   - Тритмент
   - История мира

#### Дополнительные фичи:
4. **Хронология / Таймлайн**
   - Последовательность событий вне сценария
   - Временные промежутки между сценами
   - Параллельные линии (для сериалов)

5. **Темы и мотивы**
   - Центральная тема сценария
   - Визуальные мотивы
   - Музыкальные темы (для референсов)

6. **Библиография / Референсы**
   - Похожие фильмы/сериалы
   - Книги, статьи, исследования
   - Ссылки на реальные события

7. **Глоссарий**
   - Термины мира сценария
   - Профессиональный жаргон
   - Имена собственные

### 5. ДОПОЛНИТЕЛЬНЫЕ ФИЧИ (из конкурентов)

**От Final Draft:**
- Track Changes — отслеживание изменений
- Comments — комментарии к сценам
- Revision Mode — цветные ревизии
- Tagging — теги для продакшена

**От КИТ Сценарист:**
- Статистика с графиками активности персонажей
- Тёмная/светлая тема
- Полноэкранный режим
- Подсчёт хронометража (3 системы)

**Уникальное для КиноПлана:**
- Активность персонажей по сценам
- Подсчёт локаций
- Интеграция с продакшеном (авто-Breakdown)

### 6. КАРТОЧКИ СЦЕН — Drag & Drop

**Решение:** Да, реализуем полноценный модуль карточек как в КИТ Сценарист

**Функционал:**
- ✅ Визуальная доска с карточками сцен
- ✅ **Drag & Drop** — перетаскивание для изменения порядка сцен
- ✅ Раскраска по актам / цветам / локациям
- ✅ Группировка в колонки (по актам, локациям, персонажам)
- ✅ Синхронизация с текстом — изменение в карточках меняет порядок в сценарии
- ✅ Размеры карточек: компактная / развёрнутая (с синопсисом)
- ✅ Печать карточек на бумаге (форматы A4, Letter)
- ✅ Двойной клик → переход к сцене в тексте

### 7. АНАЛИТИКА ДЛЯ СЦЕНАРИСТА

**Решение:** Полноценная аналитика как в КИТ Сценарист + уникальные метрики

**Дашборд аналитики:**

| Метрика | Описание | Визуализация |
|---------|----------|--------------|
| **Общий хронометраж** | Длительность всего сценария | Число + прогресс-бар |
| **Количество сцен** | Всего / по локациям / по персонажам | Число + список |
| **Страницы / Слова / Символы** | Объём текста | Числа |
| **Активность персонажей** | Сколько сцен с каждым персонажем | График / диаграмма |
| **Динамика сцен** | Хронометраж по сценам | Линейный график |
| **Баланс ИНТ/ЭКСТ** | Соотношение интерьер/экстерьер | Круговая диаграмма |
| **Распределение по времени суток** | ДЕНЬ / НОЧЬ / УТРО / ВЕЧЕР | Столбчатая диаграмма |
| **География локаций** | Сколько уникальных локаций | Список + карта |
| **Диалог/Ремарка** | Соотношение разговоров и действия | Проценты |
| **Средняя длина сцены** | Хронометраж в среднем | Число |
| **Самые длинные сцены** | Топ-5 по хронометражу | Список |
| **Сцены без диалога** | Только действие | Список |

**Графики и визуализации:**
- График активности персонажей по сценам (как в КИТ)
- Динамика сюжета (возрастающее напряжение)
- Карта связей персонажей (who talks to whom)
- Экспорт отчётов в PDF для продюсера

### 8. ХРОНОМЕТРАЖ — СТАНДАРТЫ И СИСТЕМЫ РАСЧЁТА

**Источники:** FilmToolz, КИТ Сценарист, StudioBinder, screenplay.com

#### Голливудский стандарт (Международный):

| Параметр | Значение |
|----------|----------|
| **Шрифт** | Courier New |
| **Размер** | 12 pt |
| **Тип шрифта** | Monospaced (fixed-width) — моноширинный |
| **Поля** | Верх/низ: 2.54 см, Лево: 3.81 см, Право: 2.54 см |
| **Персонаж** | Отступ слева: 9.3 см от края страницы |
| **Диалог** | Отступ слева: 6.35 см, справа: ~10.5 см |
| **Хронометраж** | **1 страница ≈ 1 минута экранного времени** |

**Почему Courier 12:**
- Моноширинный шрифт — каждый символ одинаковой ширины
- 10 символов = 1 дюйм горизонтально
- 6 строк = 1 дюйм вертикально
- Это обеспечивает стабильный расчёт 1 страница = 1 минута

#### Российский стандарт (КИТ Сценарист):

| Параметр | Значение |
|----------|----------|
| **Шрифт** | Courier New |
| **Размер** | 12 pt (кегль) |
| **Жирный/курсив/подчёркивание** | НИКОГДА не используются |
| **Верхнее поле** | 2.5 см |
| **Нижнее поле** | 1.25 см |
| **Левое поле** | 3.75 см |
| **Правое поле** | 2.5 см |
| **Персонаж (отступ слева)** | 6.75 см |
| **Диалог (отступ слева)** | 3.75 см |
| **Диалог (отступ справа)** | 3.75 см |
| **Ремарка (отступ слева)** | 5.5 см |
| **Ремарка (отступ справа)** | 4.5 см |

#### Системы хронометража (как в КИТ Сценарист):

**Решение:** Пользователь может выбирать систему расчёта

| Система | Принцип | Когда использовать |
|---------|---------|------------------|
| **Постраничный** | 1 страница = 1 минута | Стандартный сценарий, моноширинный шрифт |
| **Посимвольный** | N символов = 1 секунда | Нестандартное форматирование, проза |
| **Гибкий** | Комбинация методов | Длинные описания, необычная структура |
| **Ручной** | Пользователь задаёт время сцены | Известная длительность, музыкальные номера |

#### Выбор стандарта в КиноПлане:

**Настройки проекта:**
```
Формат сценария: [ ] Голливудский  [ ] Российский  [ ] Пользовательский

Система хронометража: [ ] Постраничный  [ ] Посимвольный  [ ] Гибкий
                      [ ] 1 стр = 1 мин  [ ] ___ символов = 1 сек

Шрифт: [ ] Courier New  [ ] CourierCyrillic  [ ] Другой (monospaced)
Кегль: [ 12 ] pt
Поля: [Стандартные] / [Пользовательские]
```

**Переключение "на лету":**
- Сценарист видит хронометраж в реальном времени
- Может переключить систему и увидеть пересчёт
- Экспорт с указанием использованной системы

**Расчёт для отдельной сцены:**
- Постраничный: `pages × 1 минута`
- Посимвольный: `chars ÷ chars_per_second = секунды`
- Гибкий: алгоритм КИТ (учитывает тип блоков: заголовок, ремарка, диалог)
