# Структура сценария — спецификация для парсера

> **Источник:** FilmToolz — стандарт импорта Word-файлов и форматы разметки
> **Статус:** Архитектурный документ — обязателен к чтению при изменении парсера/редактора

---

## 1. Шапка сцены (Заголовок сцены)

```
{номер}. {ИНТ./ЭКСТ.}. {локация} — {время}
{персонаж1}, {персонаж2}... (мм:сс)
```

### Правила

- **Номер:** для фильма — просто `1.`, `2.`; для сериала — `{серия}-{номер}.` (`1-1.`, `1-2.`)
- **Тип:** в КиноПлане `ИНТ.` / `ЭКСТ.` / `ИНТ-ЭКСТ.`; в FilmToolz `ИНТ.` / `НАТ.` / `НАТ/ИНТ.` / `ПАВ.`
  - `ИНТ.` = интерьер (INT.)
  - `ЭКСТ.` / `НАТ.` = экстерьер / натура (EXT.)
  - `ИНТ-ЭКСТ.` / `НАТ/ИНТ.` = смешанный тип (INT/EXT)
  - `ПАВ.` = павильон (только FilmToolz)
- **Локация:** название места действия. Может быть через точку: `Школа.Кабинет директора`
  - **Регистр важен:** `дом` и `Дом` = два разных объекта
- **Время:** `ДЕНЬ`, `НОЧЬ`, `УТРО`, `ВЕЧЕР`, `РАССВЕТ`, `ЗАКАТ`
  - В КиноПлане: после локации через тире `— ДЕНЬ`
  - В FilmToolz: после локации через пробел `день`, затем номер сценарного дня и точка `5.`

### Примеры шапки (два формата)

**КиноПлан (наш формат):**
```
1. ИНТ. КВАРТИРА ИВАНА — ДЕНЬ
МАША, ПЕТЯ (01:30)
```

**FilmToolz (для импорта):**
```
1-1. ИНТ. Школа.Кабинет директора день 5.
МАША, ПЕТЯ (01:30)

1-2. НАТ. Улица Ленина ночь.
ИВАН (00:45)

2. ПАВ. Студия A утро.
```

### Персонажи в шапке

- Указываются **необязательно** — по умолчанию импортируются из диалогов
- Нужны только для персонажей **без реплик** (например, массовка, фоновые)
- Перечисление на **второй строке** шапки через запятую
- **КРИТИЧЕСКОЕ:** переход на вторую строку — `SHIFT+ENTER`, **НЕ Enter**
  - `Shift+Enter` = новая строка внутри шапки (персонажи)
  - `Enter` = конец шапки, переход к тексту сцены (действие)
  - Если пользователь ошибочно нажал Enter — весь текст распознаётся как текст сцены

### Хронометраж в шапке

- После последнего персонажа: пробел + `(мм:сс)` в скобках
- Пример: `ИВАН, МАША (01:30)`
- Если не указан — автоматический расчёт по страницам/символам

## 2. Текст сцены (блоки)

### Действие (Action)

- Описание происходящего в сцене
- **Перед ним обязательна пустая строка** (разрыв строки)
- Первый блок после шапки

### Персонаж (Character)

- Имя героя **ВСЕГДА заглавными буквами**
- **Перед ним обязательна пустая строка**
- Отдельная строка, только имя (без реплики)

### Ремарка (Parenthetical)

- В скобках: `(описание интонации, действие)`
- Размещается **сразу после** имени персонажа
- **Ни перед, ни после не должно быть пустых строк**
- Относится к следующей реплике

### Диалог (Dialog)

- Реплика героя
- **Сразу на следующей строке** после имени персонажа (или ремарки)
- **БЕЗ пустой строки** между Character/Parenthetical и Dialog
- **Внутри диалога не должно быть разрывов строк** (одна реплика = одна строка)

### Правильная структура диалога

```
ПУСТАЯ СТРОКА
ПЕТЯ
(нервно)
Привет, Маша!

ПУСТАЯ СТРОКА
МАША
Привет, Петя.
```

**НЕПРАВИЛЬНО:**
```
ПЕТЯ

Привет!  ← пустая строка между Character и Dialog
```

**НЕПРАВИЛЬНО:**
```
ПЕТЯ
Привет,
как дела?  ← разрыв строки внутри диалога
```

## 3. Форматы отступов

### Голливудский (Hollywood)

| Блок | Отступ слева | Отступ справа |
|---|---|---|
| Action | 0 | 0 |
| Character | 9.3 см (5.5 см от поля) | — |
| Dialog | 6.35 см (2.54 от поля) | конец ~10.5 см от поля |
| Ремарка | 7.8 см (4 см от поля) | — |

### Российский (Kit-Сценарист)

| Блок | Отступ слева | Отступ справа |
|---|---|---|
| Action | 0 | 0 |
| Character | 6.75 см | — |
| Dialog | 3.75 см | 3.75 см |
| Ремарка | 5.5 см | 4.5 см |

## 4. Технические требования к шрифту

- **Шрифт:** Courier New
- **Размер:** 12
- **Жирный, курсив, подчёркивание:** НИКОГДА не используются

## 5. Влияние на наш редактор

### Что уже реализовано ✅

- Типы блоков: `sceneHeader`, `action`, `character`, `dialog`, `parenthetical`, `transition`
- Автоопределение типа по тексту (ИНТ./ЭКСТ. → sceneHeader, КАПСЛОК → character)
- Переключение RU/EN форматов (отступы)
- SmartType в шапке (ИНТ./ЭКСТ., локации, время, персонажи)

### Что нужно учесть ⚠️

1. **Shift+Enter в шапке** — сейчас не реализован. Пользователь не может добавить персонажей в шапку через Shift+Enter. Редактор сразу переходит к действию.
2. **Хронометраж в шапке** — `(мм:сс)` нужно парсить при импорте и показывать в навигаторе.
3. **Парсинг при импорте** — нужно строить на правиле "пустая строка = разделитель":
   - Строка после пустой + КАПСЛОК = Character
   - Строка в скобках после Character = Parenthetical
   - Строка после Character/Parenthetical = Dialog
   - Остальное = Action
4. **Разрывы строк внутри диалога** — редактор не должен позволять Enter внутри блока dialog. Только Shift+Enter.
5. **Персонажи без реплик** — должны быть доступны для добавления в `sceneCast` (шапка сцены) вручную.
