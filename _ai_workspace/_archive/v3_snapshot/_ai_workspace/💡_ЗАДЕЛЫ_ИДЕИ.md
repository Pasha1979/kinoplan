## 🔄 СИСТЕМА ИЗМЕНЕНИЙ СЦЕНАРИЯ (Сценарист ↔ Режиссер)

**Дата добавления:** 29.10.2026
**Статус:** 🔥 Новая критически важная идея
**Приоритет:** P0 — критично для совместной работы

### Проблема:
- Сценарист работает над сценарием
- Режиссер планирует съёмки, делает вызывные листы
- Сценарист меняет сцену → это влияет на план и съёмочный процесс
- Режиссёр должен видеть что изменилось, где и когда
- Одна и та же сцена может меняться несколько раз
- Нужно видеть все варианты изменений и не запутаться

### Решение: Система отслеживания изменений сценариев

#### 1. История изменений каждой сцены
- Автоматическое сохранение версии при каждом изменении сцены
- Версия: v1, v2, v3... с датой и временем
- Кто изменил (если будет многопользовательский режим)
- Что именно изменилось (diff)

#### 2. Визуальное выделение изменений
- В ScriptPage: показывать что сцена была изменена с последнего просмотра режиссёра
- Цветовая индикация:
  - 🟢 Зелёный — новые изменения с последнего просмотра
  - 🟡 Жёлтый — изменения > 1 дня назад
  - 🔵 Синий — изменения > 3 дней назад
- В SceneNavigator: индикатор изменения на карточке сцены

#### 3. Diff viewer (сравнение версий)
- Режим "Сравнить версии" для каждой сцены
- Показать что именно изменилось:
  - Добавленный текст — зелёный
  - Удалённый текст — красный
  - Изменённый текст — жёлтый
- Возможность переключаться между версиями (v1 → v2 → v3)

#### 4. Уведомления для режиссёра
- Smart Alert в Dashboard: "Сценарий изменён: 5 сцен обновлено"
- Список изменённых сцен с датой
- Кнопка "Просмотреть изменения"

#### 5. Влияние на план съёмок
- Если сцена изменена → показать в Schedule/Dashboard что нужно обновить
- Автоматическая пометка в вызывном листе: "Сцена обновлена — проверить"
- Если сцена удалена → показать что нужно пересмотреть план

#### 6. Синхронизация с Breakdown
- Если изменилась сцена → Breakdown автоматически обновляется
- Если добавились персонажи → обновить в библии персонажей
- Если изменилась локация → обновить в локациях

### Техническая реализация:

#### Хранение версий:
```typescript
interface SceneVersion {
  id: string
  sceneId: string
  version: number
  content: string
  timestamp: Date
  author?: string // для будущего многопользовательского режима
  changes: string[] // краткое описание изменений
}

interface Scene {
  id: string
  currentVersion: number
  versions: SceneVersion[]
  lastViewedByDirector?: Date
  // ... остальные поля
}
```

#### UI компоненты:
- `SceneVersionHistory` — история версий сцены
- `SceneDiffViewer` — сравнение двух версий
- `SceneChangeIndicator` — индикатор изменения в SceneNavigator
- `SceneChangesAlert` — уведомление об изменениях в Dashboard

### Связь с другими модулями:
- **ScriptPage** — редактор с историей изменений
- **SceneNavigator** — индикаторы изменений
- **Dashboard** — уведомления об изменениях
- **Schedule** — влияние на план съёмок
- **Breakdown** — автоматическое обновление
- **Callsheets** — пометки в вызывных листах

### Польза:
- Режиссёр всегда в курсе изменений сценария
- Минимизация ошибок при планировании съёмок
- Быстрое выявление проблемных изменений
- История всех изменений — можно откатиться
- Понятный визуальный интерфейс для diff


### Уточнение от 29.10.2026:

**Проблема с Word:**
- Много цветов изменений → не понятно когда какое изменение сделано
- Если сцена менялась много раз → сплошной цветовой хаос
- Группа не может понять хронологию изменений

**Дополнительные требования:**
1. **Уведомления для всей команды**, не только режиссёра:
   - Съёмочная группа (оператор, осветитель, звукооператор и т.д.)
   - Продюсер
   - Художник по костюмам
   - Реквизитор
   - Все кто использует сценарий

2. **Чёткая временная шкала изменений:**
   - Показывать не только "что изменилось", но и "когда"
   - Группировка изменений по версиям/дням
   - Фильтр: "Показать изменения за последние 24 часа", "за неделю", "за всё время"

3. **Понятное отображение удалений:**
   - Удалённый текст должен быть выделен так, чтобы все видели что именно удалено
   - В diff viewer: красный фон для удалённого текста
   - В SceneNavigator: пометка "Сцена сокращена" с количеством удалённых строк

4. **Решение проблемы "много цветов":**
   - Вместо сплошного цвета → группировка по версиям
   - Каждая версия = отдельный блок изменений
   - Можно показать только последнюю версию или все версии
   - Toggle: "Показать все версии" / "Только последние изменения"

### UI решения для всей команды:

#### В ScriptPage:
- Панель "История изменений" сбоку
- Список версий с датой и временем
- Можно выбрать любую версию и посмотреть diff
- Цветовая индикация: одна версия = один цвет

#### В SceneNavigator:
- На карточке сцены: индикатор изменения
- При клике → показывает краткий diff последнего изменения
- Кнопка "Показать полную историю"

#### В Dashboard:
- Для каждого пользователя: "Изменения в сценарии с последнего входа"
- Список изменённых сцен с датой
- Фильтр по типу: "Только удаления", "Только добавления", "Все изменения"

#### В Callsheets (вызывные листы):
- Пометка если сцена изменилась после формирования вызывного
- Показать что именно изменилось в вызывном
- Кнопка "Обновить вызывной"

### Техническое решение для группировки изменений:

```typescript
interface SceneVersion {
  id: string
  sceneId: string
  version: number
  content: string
  timestamp: Date
  author?: string
  changeType: 'addition' | 'deletion' | 'modification' | 'mixed'
  addedLines: number
  deletedLines: number
  modifiedLines: number
  summary: string // краткое описание: "Добавлен диалог", "Удалена локация"
}
```
