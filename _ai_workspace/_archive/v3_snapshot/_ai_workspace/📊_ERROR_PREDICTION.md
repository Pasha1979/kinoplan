## 📚 ПАТТЕРНЫ ОШИБОК

### Паттерн 1: Секреты в коде
**Признаки:**
- Добавление строки с `token`, `key`, `secret`, `password`
- Создание файла с секретами
- Коммит файла с секретами

**Предсказание:**
```
⚠️ ПРЕДУПРЕЖДЕНИЕ: Вероятно GitHub Secret Blocking

Если добавишь секрет в код без .env, GitHub заблокирует пуш.
Решение: Добавь секрет в .env файл (защищён .gitignore).

Продолжить? (да/нет/исправить)
```

---

### Паттерн 2: TypeScript ошибки на Vercel
**Признаки:**
- Изменение .ts/.tsx файлов
- Коммит без `npm run build`
- Изменение типов

**Предсказание:**
```
⚠️ ПРЕДУПРЕЖДЕНИЕ: Вероятно TypeScript ошибки на Vercel

Если закоммитишь без `npm run build`, Vercel не соберётся.
Решение: Запусти `npm run build` перед коммитом.

Продолжить? (да/нет/проверить)
```

---

### Паттерн 3: Потеря контекста
**Признаки:**
- Контекст > 140k токенов
- Длинная история диалога
- Много сообщений

**Предсказание:**
```
⚠️ ПРЕДУПРЕЖДЕНИЕ: Вероятно потеря контекста

Контекст близок к лимиту (140k/158k).
Решение: Автосохранение будет запущено автоматически.

Хотите сохранить контекст сейчас?
```

### Паттерн 4: Нарушение архитектуры
**Признаки:**
- Прямой доступ к SQLite из React
- Локальный useState для глобальных данных
- Отсутствие IPC

**Предсказание:**
```
⚠️ ПРЕДУПРЕЖДЕНИЕ: Вероятно нарушение архитектуры

Похоже на прямое обращение к SQLite из React.
Решение: Используй IPC и repositories.

Продолжить? (да/нет/исправить)
```
