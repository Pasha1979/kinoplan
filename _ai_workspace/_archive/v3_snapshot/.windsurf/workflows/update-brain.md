# Workflow: Обновление AI-мозга

При вызове этого workflow выполни:

1. Прочитай все файлы в `_ai_workspace/`:
   - 🧠_МОЗГ_ПРОЕКТА.md
   - 📊_ТЕКУЩИЙ_СТАТУС.md
   - LESSONS_LEARNED.md
   - ARCHITECTURE_GUARDIAN.md

2. Проанализируй что было сделано в текущей сессии (по истории чата)

3. Обнови файлы:
   - **📊_ТЕКУЩИЙ_СТАТУС.md**: отметь выполненное, напиши что осталось, добавь следующий шаг
   - **LESSONS_LEARNED.md**: если были ошибки или неочевидные моменты, добавь урок
   - **ARCHITECTURE_GUARDIAN.md**: если изменились архитектурные решения, обнови
   - **🧠_МОЗГ_ПРОЕКТА.md**: если произошли важные события, добавь их с датой

4. Запусти Memory Triggers:
   - Автоматически обновить 📊_ТЕКУЩИЙ_СТАТУС.md
   - Предложить обновить ПЛАН_РАБОТ.md

5. Запусти Next Steps Recommender:
   - Проанализировать ПЛАН_РАБОТ.md
   - Предложить топ-3 следующих шага

6. Сообщи пользователю что мозг обновлён и кратко резюмируй изменения

7. Подтверди что все файлы сохранены

8. **Обязательно** выполни коммит и пуш:
   - `git add .`
   - `git commit -m "feat/fix: <краткое описание сессия>"`
   - `git push`
   - Проверить Vercel деплой
