### Типы данных (ScriptStore)

```typescript
// Элемент разбивки сцены
type BreakdownCategory =
  | 'cast'        // Актёры / роли
  | 'extras'      // Массовка
  | 'props'       // Реквизит
  | 'costumes'    // Костюмы
  | 'locations'   // Локации
  | 'vehicles'    // Транспорт
  | 'sfx'         // Спецэффекты
  | 'stunts'      // Трюки
  | 'vfx'         // VFX
  | 'notes'       // Прочие заметки

interface BreakdownElement {
  id: string
  category: BreakdownCategory
  name: string             // например «ИВАН», «Пистолет», «Квартира Ивана»
  notes?: string
}

interface Scene {
  id: string
  projectId: string
  number: string           // «1», «2А», «3» — может быть буквенным
  type: 'INT' | 'EXT' | 'INT/EXT'   // ИНТ / ЭКСТ
  location: string         // «КВАРТИРА ИВАНА»
  timeOfDay: 'DAY' | 'NIGHT' | 'DAWN' | 'DUSK' | 'CONTINUOUS'
  synopsis: string         // краткое описание действия
  pages: number            // хронометраж в страницах (0.125 = 1/8 стр.)
  cast: string[]           // имена персонажей в сцене
  breakdownElements: BreakdownElement[]
  scriptText?: string      // полный текст сцены (из редактора)
  colorTag?: string        // цветная ревизия (белый/синий/розовый...)
  isOmitted: boolean       // сцена исключена из съёмок
  order: number            // порядок в сценарии
}

interface Script {
  id: string
  projectId: string
  title: string
  version: string          // «Съёмочный», «Режиссёрский», «Черновик v3»
  format: 'russian' | 'hollywood'
  scenes: Scene[]
  characters: Character[]  // справочник персонажей
  createdAt: string
  updatedAt: string
}

interface Character {
  id: string
  name: string             // «ИВАН» — всегда капслок
  description?: string
  sceneCount: number       // сколько сцен участвует (вычисляется)
}
```

### Редактор — блочные элементы (форматирование)

| Тип блока     | Русское название   | Горячая клавиша | Авто-переход |
|---------------|--------------------|-----------------|---------------|
| `scene_header`| Заголовок сцены    | Tab из action   | → action      |
| `action`      | Описание действия  | Enter           | → action      |
| `character`   | Персонаж           | Tab из action   | → dialog      |
| `dialog`      | Диалог             | Enter           | → character   |
| `parenthetical`| Ремарка           | Tab из dialog   | → dialog      |
| `transition`  | Переход            | Tab из action   | → scene       |

**Авто-форматирование:**
- Ввёл «инт.» или «INT.» → блок стал `scene_header`
- Ввёл имя персонажа капслоком на пустой строке → стало `character`
- SmartType: автодополнение имён персонажей и локаций из справочника
- Российский формат: отступы по стандарту КИТ Сценариста

### 1. СТРУКТУРА МОДУЛЯ «СЦЕНАРИЙ» — Гибрид А+

**Решение:** Используем гибридный подход — вкладки внутри модуля + быстрые ссылки в сайдбаре

```
САЙДБАР                    ВНУТРИ МОДУЛЯ «СЦЕНАРИЙ»
├── 🏠 Дашборд             ┌─────────────────────────────────────────┐
├── 📝 СЦЕНАРИЙ      →     │  ТЕКСТ  │  КАРТОЧКИ  │  РАЗРАБОТКА  │📊│
├── 👥 Персонажи     →     ├─────────────────────────────────────────┤
├── 🏢 Локации       →     │                                         │
├── 📊 Статистика    →     │  [Контент активной вкладки]            │
└── 🎬 Продакшен    →     │                                         │
                           └─────────────────────────────────────────┘
```

**Обоснование:**
- Контекст сценария сохраняется (вкладки)
- Быстрый доступ к персонажам/локациям из сайдбара
- Масштабируемость без перегрузки интерфейса
- Близко к привычному КИТ Сценарист

---

### 2. АВТО-ФОРМАТИРОВАНИЕ — Гибридный подход

**Решение:** Объединяем умное распознавание + ручное управление Tab/Enter

#### Умное распознавание (по умолчанию):
| Что пишет пользователь | Распознаётся как |
|------------------------|------------------|
| `ИНТ.` / `ЭКСТ.` / `ИНТ./ЭКСТ.` | Заголовок сцены |
| `НАПЛЫВ:` / `СМЕНА ПЛАНА:` | Переход |
| ВСЕ ЗАГЛАВНЫЕ (2+ слова) | Имя персонажа |
| Обычный текст после имени | Диалог |
| Текст в скобках `(взволнованно)` | Ремарка в диалоге |
| Текст без заглавных | Описание действия (ремарка) |

#### Ручное управление (Tab/Enter):
- **Tab** — переключить тип текущего абзаца циклически:
  `Заголовок → Ремарка → Персонаж → Диалог → Проходка → Ремарка`
- **Enter** в конце диалога → автоматически переход к ремарке (готовность к следующей сцене)

### 8. ХРОНОМЕТРАЖ — СТАНДАРТЫ И СИСТЕМЫ РАСЧЁТА

**Источники:** FilmToolz, КИТ Сценарист, StudioBinder, screenplay.com

#### Голливудский стандарт (Международный):

| Параметр | Значение |
|----------|----------|
| **Шрифт** | Courier New |
| **Размер** | 12 pt |
| **Тип шрифта** | Monospaced (fixed-width) — моноширинный |
| **Поля** | Верх/низ: 2.54 см, Лево: 3.81 см, Право: 2.54 см |
| **Персонаж** | Отступ слева: 9.3 см от края страницы |
| **Диалог** | Отступ слева: 6.35 см, справа: ~10.5 см |
| **Хронометраж** | **1 страница ≈ 1 минута экранного времени** |

**Почему Courier 12:**
- Моноширинный шрифт — каждый символ одинаковой ширины
- 10 символов = 1 дюйм горизонтально
- 6 строк = 1 дюйм вертикально
- Это обеспечивает стабильный расчёт 1 страница = 1 минута

#### Российский стандарт (КИТ Сценарист):

| Параметр | Значение |
|----------|----------|
| **Шрифт** | Courier New |
| **Размер** | 12 pt (кегль) |
| **Жирный/курсив/подчёркивание** | НИКОГДА не используются |
| **Верхнее поле** | 2.5 см |
| **Нижнее поле** | 1.25 см |
| **Левое поле** | 3.75 см |
| **Правое поле** | 2.5 см |
| **Персонаж (отступ слева)** | 6.75 см |
| **Диалог (отступ слева)** | 3.75 см |
| **Диалог (отступ справа)** | 3.75 см |
| **Ремарка (отступ слева)** | 5.5 см |
| **Ремарка (отступ справа)** | 4.5 см |

#### Системы хронометража (как в КИТ Сценарист):

**Решение:** Пользователь может выбирать систему расчёта

| Система | Принцип | Когда использовать |
|---------|---------|------------------|
| **Постраничный** | 1 страница = 1 минута | Стандартный сценарий, моноширинный шрифт |
| **Посимвольный** | N символов = 1 секунда | Нестандартное форматирование, проза |
| **Гибкий** | Комбинация методов | Длинные описания, необычная структура |
| **Ручной** | Пользователь задаёт время сцены | Известная длительность, музыкальные номера |

#### Выбор стандарта в КиноПлане:

**Настройки проекта:**
```
Формат сценария: [ ] Голливудский  [ ] Российский  [ ] Пользовательский

Система хронометража: [ ] Постраничный  [ ] Посимвольный  [ ] Гибкий
                      [ ] 1 стр = 1 мин  [ ] ___ символов = 1 сек

Шрифт: [ ] Courier New  [ ] CourierCyrillic  [ ] Другой (monospaced)
Кегль: [ 12 ] pt
Поля: [Стандартные] / [Пользовательские]
```

**Переключение "на лету":**
- Сценарист видит хронометраж в реальном времени
- Может переключить систему и увидеть пересчёт
- Экспорт с указанием использованной системы

**Расчёт для отдельной сцены:**
- Постраничный: `pages × 1 минута`
- Посимвольный: `chars ÷ chars_per_second = секунды`
- Гибкий: алгоритм КИТ (учитывает тип блоков: заголовок, ремарка, диалог)

### Hover Lift — подъём при наведении
Все кликабельные карточки и главные кнопки используют эффект подъёма:
```
transition-all duration-200
hover:-translate-y-1        ← карточки (ProjectCard, карточки выбора)
hover:-translate-y-0.5      ← кнопки (CTA, «Новый проект», «Создать»)
active:translate-y-0        ← возврат при клике
```

### Hover Glow — усиление тени
```
hover:shadow-xl hover:shadow-[accentColor]/10-25
```
- Оранжевые кнопки: `hover:shadow-orange-500/40`
- Карточки сценария (индиго): `hover:shadow-[rgba(99,102,241,0.25)]`
- Карточки (зелёные): `hover:shadow-[rgba(16,185,129,0.2)]`

### Принцип
- **Карточки** (ProjectCard, карточки выбора пути) — `hover:-translate-y-1`
- **CTA-кнопки** (Создать, Загрузить, Сохранить) — `hover:-translate-y-0.5`
- **Навигация сайдбара** — без подъёма, только цвет/фон
- **Деструктивные кнопки** (Удалить) — без подъёма, только цвет
