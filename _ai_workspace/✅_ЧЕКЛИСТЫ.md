## 📋 ЧЕК-ЛИСТ ПЕРЕД КАЖДЫМ ОТВЕТОМ (ОБЯЗАТЕЛЬНО)

Перед каждым ответом пользователю выполни:

1. **Контекст**: Прочитать `CURRENT_STEP.md` и `ПЛАН_РАБОТ.md` 
2. **Архитектура**: Проверить `ПРАВИЛА_АРХИТЕКТУРЫ.md` — не нарушаю ли я её?
3. **Идеи**: Проверить `💡_ЗАДЕЛЫ_И_ИДЕИ.md` — не предлагаю ли я то, что уже есть?
4. **Конкуренты**: Проверить `🔬_АНАЛИЗ_КОНКУРЕНТОВ_РЕДАКТОР.md` — можно ли улучшить на основе их опыта?
5. **Ответвления**: Проверить `СТРУКТУРА_ПЛАНИРОВАНИЯ.md` — есть ли незавершенные ответвления?

Если найдено нарушение или пропуск — ИСПРАВИТЬ перед ответом.

---

## 📋 ЧЕК-ЛИСТ ПОСЛЕ КАЖДОГО ОТВЕТА (ОБЯЗАТЕЛЬНО)

После каждого ответа пользователю выполни:

1. **Идеи**: Записал ли я все новые идеи в `💡_ЗАДЕЛЫ_И_ИДЕИ.md`?
2. **Замечания**: Записал ли я замечания пользователя в `📝_ЗАМЕЧАНИЯ_ПОЛЬЗОВАТЕЛЯ.md`?
3. **Руководства**: Записал ли я новые правила в `📋_РУКОВОДСТВА.md`?
4. **Успехи**: Записал ли я достижения в `🏆_ЖУРНАЛ_УСПЕХОВ.md`?
5. **План**: Обновил ли я `ПЛАН_РАБОТ.md`, если изменились приоритеты?
6. **Нейронные связи**: Обновил ли я зависимые файлы (см. `🧠_МОЗГ_ПРОЕКТА.md`)?

7. **Автоматическое обновление плана:**
   - Упомянул ли пользователь новую идею/фичу/визуал?
   - Если ДА → добавил ли я это в `💡_ЗАДЕЛЫ_И_ИДЕИ.md`?
   - Изменились ли приоритеты?
   - Если ДА → обновил ли я `ПЛАН_РАБОТ.md`?
   - Есть ли новые заглушки?
   - Если ДА → зафиксировал ли я это в плане?

8. **Проверка методологии:**
   - Прочитал ли я `РАБОЧИЙ_ПРОЦЕСС.md` → раздел "МЕТОДОЛОГИЯ РАЗРАБОТКИ"?
   - Следую ли я правилам о заглушках?
   - Фиксирую ли я связывание модулей?

Если что-то пропущено — ДОБАВИТЬ немедленно.

## 📋 ЧЕК-ЛИСТ: Git Workflow

### После каждого завершённого шага
```bash
# 1. Добавить все изменения
git add .

# 2. Commit с описанием изменений
git commit -m "описание"

# 3. Push в main (синхронизация с GitHub)
git push origin main

# 4. Vercel деплой запустится автоматически
```

### Проверка
- [ ] GitHub обновлён: https://github.com/Pasha1979/kinoplan
- [ ] Vercel пересобрал: https://kinoplan.vercel.app
- [ ] Локальный сервер работает: http://localhost:5173/

**Команды (PowerShell):**
```powershell
$env:PATH = "C:\Program Files\nodejs;" + $env:PATH
git add .
git commit -m "описание"
git push
```
