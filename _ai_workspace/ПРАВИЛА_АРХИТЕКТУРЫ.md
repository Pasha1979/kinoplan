## 🚫 ЖЕСТКИЕ ЗАПРЕТЫ

### 1. Прямые импорты браузерных API в компонентах
**ЗАПРЕЩЕНО:**
```typescript
import { localStorage } from '...'  // ❌
import { fetch } from '...'         // ❌
import axios from 'axios'           // ❌
```

**РЕШЕНИЕ:**
- Использовать сервисы из `src/services/`
- Использовать адаптеры из `src/adapters/`
- Использовать безопасные утилиты из `src/utils/env.ts`

---

### 2. Хранение общих данных в useState компонентов
**ЗАПРЕЩЕНО:**
```typescript
const [projects, setProjects] = useState([])  // ❌ если данные общие
```

**РЕШЕНИЕ:**
- Хранить общие данные в Zustand сторе
- Использовать `useProjectStore`, `useScriptStore` и т.д.
- Для локального состояния компонента — useState разрешен

---

### 3. Обработка ошибок без toast-уведомлений
**ЗАПРЕЩЕНО:**
```typescript
try {
  // ...
} catch (err) {
  console.error(err)  // ❌
  // или ничего не делать
}
```

**РЕШЕНИЕ:**
```typescript
try {
  // ...
} catch (err) {
  showToast('Не удалось выполнить действие', 'error')  // ✅
}
```

---

### 4. Прямые обращения к window, document, localStorage
**ЗАПРЕЩЕНО:**
```typescript
window.scrollTo(0, 0)           // ❌
document.getElementById('...')   // ❌
localStorage.getItem('...')      // ❌
```

**РЕШЕНИЕ:**
```typescript
const win = safeGetWindow()
win?.scrollTo(0, 0)            // ✅

const doc = safeGetDocument()
doc?.getElementById('...')      // ✅

safeGetLocalStorage('...')     // ✅
safeSetLocalStorage('...', '...')  // ✅
```

## ✅ ОБЯЗАТЕЛЬНЫЕ ПАТТЕРНЫ

### 1. Все файловые операции через FileSystemAdapter
```typescript
// ❌ Прямой вызов браузерного API
const blob = new Blob([content])
const url = URL.createObjectURL(blob)
// ...

// ✅ Через адаптер
await browserFS.downloadFile(filename, content, mimeType)
```

### 2. Все глобальные обращения через env.ts
```typescript
// ❌ Прямое обращение
if (typeof window !== 'undefined') {
  window.addEventListener('...')
}

// ✅ Через утилиту
const win = safeGetWindow()
win?.addEventListener('...')
```

### 3. Все ошибки через toast-систему
```typescript
// ❌ Игнорирование ошибок
try {
  await projectService.saveProject()
} catch {
  // ничего
}

// ✅ Обработка через toast
try {
  await projectService.saveProject()
  showToast('Проект сохранен', 'success')
} catch (err) {
  showToast('Не удалось сохранить проект', 'error')
}
```

## 🔍 АВТОМАТИЧЕСКАЯ ПРОВЕРКА

**Скрипт:** `scripts/check-architecture.ps1`

**Проверяет:**
- Прямые вызовы `localStorage.getItem` / `localStorage.setItem`
- Прямые вызовы `window.` / `document.`
- Прямые вызовы `console.log` / `console.error`

**Исключения:**
- `src/utils/env.ts` — здесь разрешены прямые обращения
- `src/adapters/` — здесь разрешены прямые обращения
- `.test.ts` файлы — тесты могут использовать console
