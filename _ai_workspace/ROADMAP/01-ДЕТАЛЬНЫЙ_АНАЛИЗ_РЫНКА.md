🔍 ДЕТАЛЬНЫЙ АНАЛИЗ ПО КАЖДОМУ НАПРАВЛЕНИЮ
🎭 1. РАБОТА СО СЦЕНАРИЕМ (SCRIPT MANAGEMENT)
Filmtoolz
✅ ИМПОРТ И АНАЛИЗ:
• Импорт сценариев из .fdx (Final Draft), PDF, DOCX
• Автоматическая аналитика: подсчет сцен по локациям, персонажам, времени суток
• Авто-расчет хронометража на основе стандартных норм (1 стр. = ~1 мин)
• Цветовая маркировка: интерьер/экстерьер/павильон

✅ УПРАВЛЕНИЕ ВЕРСИЯМИ:
• Отслеживание готовности сценария по сценам
• Возможность комментирования сцен внутри платформы
• Интеграция с модулем препродакшна для кастинг-листов

❌ ОГРАНИЧЕНИЯ:
• Нет встроенного редактора сценариев (только импорт)
• Автоматическая разбивка требует ручной проверки

Movie Magic Scheduling
✅ ГИБКОСТЬ РАЗБИВКИ:
• Ручной импорт элементов: персонажи, реквизит, локации, транспорт
• Полная кастомизация категорий breakdown (до 64 пользовательских полей)
• Возможность группировки сцен по любому параметру

✅ ПРОФЕССИОНАЛЬНЫЙ КОНТРОЛЬ:
• Точная настройка хронометража по сценам
• Поддержка сложных сценарных структур (флэшбеки, параллельные линии)
• Экспорт breakdown-листов в индустриальных форматах

❌ ОГРАНИЧЕНИЯ:
• Полностью ручной процесс теггинга — трудоемко для больших проектов
• Нет авто-аналитики: все метрики считаются вручную
• Требует обучения: интерфейс не интуитивен для новичков

SetHero

✅ ПРАКТИЧНОСТЬ:
• Возможность прикреплять PDF-сценарий к проекту как референс
• Ссылки на сцены внутри call sheets для быстрого доступа

❌ ОГРАНИЧЕНИЯ:
• ❌ Нет функционала работы со сценарием как таковым
• ❌ Нет импорта, разбивки, аналитики сцен
• Позиционируется как инструмент для этапа съемок, не препродакшна

📌 Вывод: Для работы со сценарием SetHero не подходит — требуется отдельный инструмент.


📅 2. ПЛАНИРОВАНИЕ СЪЕМОК (SHOOTING SCHEDULE)
Filmtoolz
✅ ИНТЕРФЕЙС И ЛОГИКА:
• Визуальный календарь с drag&drop-перемещением сцен [[8]]
• Два режима отображения: по локациям / по приоритету (как в вызывном)
• Цветовая индикация: серая (не распланирована), красная (пересъемка), желтая (доп. съемки)

✅ МНОГОПОТОЧНОСТЬ:
• Планирование для 1-3 съемочных групп одновременно [[6]]
• Автоматические уведомления о конфликтах занятости актеров
• Учет погодных условий (интеграция с гео-настройками проекта)

✅ ГИБКОСТЬ:
• Быстрое изменение типа дня: рабочий/выходной/ночная смена/подготовка
• Блокировка дня от случайных правок
• Экспорт расписания в Excel/PDF с настраиваемыми полями

❌ ОГРАНИЧЕНИЯ:
• Меньше глубины кастомизации, чем у Movie Magic
• Нет sub-boards для сложных эпизодических проектов

Movie Magic Scheduling

✅ ИНДУСТРИАЛЬНАЯ МОЩЬ:
• Классический stripboard-интерфейс — стандарт Голливуда [[33]]
• Side-by-side view: одновременная работа с доской и отчетами
• Продвинутый конфликт-детекшн: автоматическая проверка пересечений ресурсов [[33]]

✅ СЛОЖНЫЕ ПРОЕКТЫ:
• Multi-episode management: блок-шуты, кросс-борды для сериалов [[33]]
• Sub-boards: отдельные расписания для 2-4 съемочных групп с объединением в мастер-план
• Comprehensive Calendar: единый календарь для съемок, репетиций, примерок, логистики

✅ КАСТОМИЗАЦИЯ:
• Полная настройка цветов, шрифтов, структуры доски и отчетов
• Автоматические разрывы страниц в one-line schedules
• Экспорт в Excel с сохранением форматирования

❌ ОГРАНИЧЕНИЯ:
• Высокий порог входа: требуется обучение и опыт
• Десктоп-приложение: нет облачной коллаборации в реальном времени
• Нет встроенной базы актеров — занятость вносится вручную

SetHero
✅ ПРОСТОТА И СКОРОСТЬ:
• Интуитивный интерфейс: создание расписания через call sheet builder
• Быстрое изменение порядка сцен внутри дня

❌ ОГРАНИЧЕНИЯ:
• ❌ Нет полноценного stripboard или визуального планировщика
• ❌ Нет аналитики по локациям/персонажам/хронометражу
• ❌ Нет multi-unit планирования
• Планирование сводится к заполнению полей вызывного листа

📌 Вывод: SetHero — инструмент для фиксации уже принятого расписания, не для его стратегического планирования.

📋 3. ВЫЗЫВНЫЕ ЛИСТЫ (CALL SHEETS) — «ВЫЗЫВАЙ»
Filmtoolz
✅ ФУНКЦИОНАЛ КОНСТРУКТОРА:
• Визуальный редактор вызывных с предпросмотром [[4]]
• Автоматическое подтягивание данных из расписания: сцены, актеры, локации
• Сценарные разрезки: автоматическая генерация списка сцен на день

✅ ЭКСПОРТ И РАССЫЛКА:
• Выгрузка в Excel и PDF с настраиваемыми шаблонами [[4]]
• Массовая рассылка вызывных съемочной группе через платформу
• Интеграция с производственными отчетами: авто-заполнение факта

✅ КОНТРОЛЬ:
• Трекинг: кто получил, кто открыл вызывной (базовый уровень)
• Версионность: история изменений вызывного листа

❌ ОГРАНИЧЕНИЯ:
• Мобильная версия — адаптивная веб, не нативное приложение
• Меньше визуальной кастомизации, чем у SetHero
• Нет SMS-уведомлений в реальном времени

Movie Magic Scheduling

✅ ПРОФЕССИОНАЛЬНЫЕ ОТЧЕТЫ:
• Генерация call sheets через систему отчетов (Day-Out-Of-Days, One-Line)
• Полная кастомизация полей и форматирования
• Интеграция с Movie Magic Budgeting: авто-перенос данных о затратах

✅ СТАНДАРТЫ ИНДУСТРИИ:
• Форматы, принятые в Голливуде и международных ко-продакшнах
• Поддержка сложных структур: multi-cam, VFX-дни, second unit

❌ ОГРАНИЧЕНИЯ:
• ❌ Нет встроенного «конструктора» call sheet — только экспорт отчетов
• ❌ Нет цифрового распространения: файлы выгружаются и рассылаются вручную
• ❌ Нет трекинга открытий/подтверждений
• Требует отдельного ПО для коммуникации с группой

SetHero — 🏆 ЛИДЕР В КАТЕГОРИИ CALL SHEETS
✅ УНИКАЛЬНЫЕ ПРЕИМУЩЕСТВА:
• 🎯 Drag&drop builder: создание вызывного за ~20 минут без Excel [[18]]
• 📱 Персонализация: каждый член группы получает call sheet с релевантной для него информацией [[21]]
• 📬 Мультиканальная доставка: ссылка в SMS, email, мессенджеры + печатная версия
• 👁️ Трекинг в реальном времени: кто получил, открыл, подтвердил участие [[21]]
• 🔄 Авто-обновления: изменения в расписании мгновенно отражаются у всех получателей

✅ ДОПОЛНИТЕЛЬНЫЕ ФИЧИ:
• Карта локации с интеграцией Google Maps («как Google Maps для вашей съемки») [[21]]
• Встроенный чат для оперативных вопросов по вызывному
• Архив вызывных с поиском по проектам/датам

✅ МОБИЛЬНОСТЬ:
• Нативные приложения iOS/Android для съемочной группы
• Оффлайн-доступ к загруженным вызывным

❌ ОГРАНИЧЕНИЯ:
• ❌ Нет глубокой интеграции с планированием: call sheet создается «вручную» на основе внешнего расписания
• ❌ Нет аналитики по сценарию/бюджету
• ❌ Нет встроенной базы актеров — контакты вносятся вручную
