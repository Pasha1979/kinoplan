🏗️ АРХИТЕКТУРА И ТЕХНИЧЕСКАЯ МОДЕЛЬ (ОБНОВЛЁННАЯ)

• Технология: Electron + React/Vue (кроссплатформенность, нативный опыт)

🔐 Безопасность на устройстве:

🧩 ДЕТАЛЬНЫЙ ФУНКЦИОНАЛ ПО МОДУЛЯМ
📜 МОДУЛЬ 1: РЕДАКТОР СЦЕНАРИЕВ + АНАЛИТИКА (ЯДРО ПРОДУКТА)
✅ Профессиональный редактор (встроенный):
• Автоформатирование по стандартам: 
  - Сценозаголовки (ИНТ./ЭКСТ. МЕСТО — ВРЕМЯ)
  - Действие, персонажи, диалоги, ремарки — всё форматируется автоматически
  - Горячие клавиши для быстрого ввода (как в Final Draft)
• Поддержка кириллицы: корректная работа с русскими именами, локациями, типографикой
• Нумерация сцен: авто-присвоение и пересчет при добавлении/удалении сцен
• Цветовые ревизии: пометка измененных сцен (синий/розовый/желтый и т.д.)

✅ Импорт/Экспорт:
• Импорт: .fdx (Final Draft), .pdf, .docx, .fountain, .kit (KitScenarist)
• Экспорт: .fdx, .pdf (сценарий + вызывной формат), .docx, .txt, .csv (для аналитики)
• Двусторонняя синхронизация: изменения в импортированном .fdx подхватываются при повторном открытии

✅ Автоматическая аналитика и разбивка:
• 🤖 Авто-парсинг: распознавание персонажей, локаций, времени суток, реквизита из текста
• 📊 Статистика в реальном времени:
  - Общее количество сцен, страниц, расчетный хронометраж
  - Распределение по локациям (ИНТ/ЭКСТ), времени суток, дням недели
  - Занятость персонажей: кто в каких сценах, общий вес роли
• 🏷️ Гибкая система тегов:
  - Предопределенные категории: Локация, Персонаж, Реквизит, Транспорт, Эффекты, Каски
  - Кастомные теги: до 32 пользовательских категорий с цветовым кодированием
  - Массовое присвоение: выделение нескольких сцен → применение тега ко всем

✅ Управление версиями и коллаборация:
• Ветвление: черновик → лок-скрипт → съемочный → пост-версия
• Сравнение версий: визуальная дифф-подсветка изменений в тексте и метаданных
• Комментарии: привязка заметок к конкретным сценам или репликам
• Синхронизация изменений: при подключении к интернету — автоматическое слияние правок от разных участников (с разрешением конфликтов)

✅ Интеграция с планированием:
• Одна кнопка: «Создать расписание на основе сценария» → авто-генерация черновика stripboard
• При изменении сценария: уведомление о влиянии на расписание («Сцена 24 перенесена — проверить локацию»)

📅 МОДУЛЬ 2: ПЛАНИРОВАНИЕ СЪЕМОК (SCHEDULING)
✅ Визуальный Stripboard (интуитивный + мощный):
• Drag&drop-интерфейс: перетаскивание сцен между днями, группами, локациями
• Горизонтальная шкала времени: дни съемок, вертикально — сцены/группы
• Цветовая кодировка: настраиваемая палитра по локациям, персонажам, типу сцены, приоритету
• Sub-boards: отдельные доски для 2-3 съемочных групп с объединением в мастер-план

✅ Умное планирование:
• Конфликт-детекшн в реальном времени:
  - Пересечение занятости актеров (на основе кастинг-листов)
  - Наложение локаций (одна локация — две группы в один день)
  - Превышение дневного лимита: страниц, сцен, расчетного хронометража
• Авто-оптимизация (опционально): предложение альтернативного порядка сцен для минимизации переездов
• Учет российских норм:
  - Макс. продолжительность съемочного дня (с учетом ТК РФ)
  - Обязательные перерывы, ночные смены, работа с детьми и животными

✅ Сериальный движок:
• Шаблоны эпизодов: копирование структуры расписания между сериями
• Кросс-эпизодное планирование: сцены из разных серий в одной локации — одним блоком
• Управление «блоками съемок»: по локациям / по актерам / по хронологии
• Трекинг прогресса: % готовности по сериям, визуализация отставания от графика

✅ Экспорт и интеграция:
• Выгрузка расписания: PDF (формат вызывного), Excel (для внутреннего учета), iCal (для календарей)
• Интеграция с модулем вызывных: авто-перенос данных для генерации «Вызывая»
• Печать «производственной книги»: комплект документов для съемочной группы (расписание + контакты + карты)

📋 МОДУЛЬ 3: ВЫЗЫВНЫЕ ЛИСТЫ («ВЫЗЫВАЙ»)

✅ Конструктор вызывных (гибкий + быстрый):
• Визуальный builder: перетаскивание блоков (сцены, каст, крю, локация, погода, контакты)
• Шаблоны под форматы: сериал / полнометражка / реклама / ТВ-шоу / клип
• Авто-заполнение: данные подтягиваются из расписания, сценария и базы контактов

✅ Персонализация выдачи:
• Ролевая фильтрация: каждый получает версию с релевантной информацией
  - Актер: только его сцены, гримерка, контакт 2-го режиссера
  - Водитель: адреса, тайминг переездов, контакты логиста
  - Скрипт-супервайзер: нумерация сцен, дубли, заметки по хронометражу
• Форматы вывода:
  - 🖨️ Печать: оптимизированный PDF для распечатки на площадке
  - 📱 Мобильный просмотр: адаптивная верстка для телефона/планшета
  - 💻 Экспорт: Excel/CSV для дальнейшей обработки

✅ Коммуникация (при подключении к интернету):
• Рассылка по email: массовая отправка вызывных с персонализированными вложениями
• SMS-уведомления: краткое сообщение со ссылкой на вызывной (интеграция с российскими SMS-шлюзами)
• Трекинг: журнал отправки, статусы «доставлено», «прочитано» (в рамках приложения)
• Экстренные обновления: при изменении расписания — рассылка алерта «ВНИМАНИЕ: ИЗМЕНЕНИЯ В ВЫЗЫВНОМ»

✅ Контроль и версионность:
• История вызывных: архив всех версий с комментариями, кто и зачем правил
• Подтверждения: электронная галочка о ознакомлении (внутри приложения)
• Резервная копия: авто-сохранение каждой версии на локальном диске/

🎭 МОДУЛЬ 4: ПРЕ-ПРОДАКШН (БЕЗ БАЗЫ АКТЕРОв, БЕЗ БЮДЖЕТА)

✅ Управление кастингом (локальный фокус):
• Проектная база актеров: профили утвержденных на текущий проект (фото, контакты, заметки)
• Кастинг-листы: создание списков на роли, статусы (приглашен / утвержден / отказ), заметки по пробам
• Видео-пробы: загрузка видеофайлов (локальное хранение), привязка к профилям и сценам
• Ансамбли: группировка актеров по сценам для быстрого подбора в расписание

✅ Локации и реквизит:
• Каталог локаций: фото, адреса, контакты владельцев, условия, история использования в проектах
• Привязка к сценарию: авто-формирование списка локаций по сценарным объектам
• Учет реквизита и костюмов: чек-листы по сценам, ответственные, статус готовности (✅/⏳/❌)

✅ Управление командой:
• База контактов проекта: роли, телефоны, мессенджеры, зоны ответственности
• Быстрый доступ: поиск по имени/роли, мгновенный запуск звонка/сообщения (при наличии интернета)

✅ Аналитика препродакшна:
• Дашборд проекта: % готовности сценария, кастинга, локаций
• Прогноз рисков: автоматическое выделение «узких мест» (дефицит актеров, сложные локации)
• Экспорт сводок: одностраничный отчет для продюсера (текст + графики)
