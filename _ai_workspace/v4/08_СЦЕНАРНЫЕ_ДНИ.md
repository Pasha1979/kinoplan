# 08 · СЦЕНАРНЫЕ ДНИ (спека, зафиксирована 22.11.2026)
> Модуль: сценарий. Все решения приняты пользователем. Скоуп: парсер/типы/валидация/SmartType/автоформат/UI/статистика/перенос/пересчёт + тесты. НЕ трогать `shootDayNumber` и другие модули.

## СУЩНОСТИ (три разные)
- **time** — строка как написал автор («ДЕНЬ 32», «НОЧЬ 1», «ДЕНЬ Х») — для экспорта/пагинации.
- **mode** — УТРО/ДЕНЬ/ВЕЧЕР/НОЧЬ/РАССВЕТ/ЗАКАТ — для статистики/автозамен/перехода к составу.
- **storyDay** — `{kind:'normal'|'special', value:number|null, raw:string}`.
  - normal = 1, 2, 32…
  - special = 0, −N, +N, Х, и ФБ/ФЛЕШБЕК/ФФ
  - Спец — ОДНИМ цветом, НЕ в счётчике; относительные (−N/+N) считать от текущего дня; бейдж показывает «сырое» (ДЕНЬ −3).
- **shootDayNumber** (съёмочный день) — ОТДЕЛЬНОЕ поле, НЕ трогать.

## ПРОЕКТ
- Переключатель «Сценарные дни»: вкл по умолчанию для сериал/полный метр; выкл для клип/реклама.
- Legacy-проекты не спамить предупреждениями.
- Дни СКВОЗНЫЕ по сезону (сериал) и в полном метре.

## ВАЛИДАЦИЯ
- День обязателен → отсутствует = МЯГКОЕ предупреждение + подсказка номера по логике сезона.
- День без режима («...ДЕЖУРКА. 32») = принять день + МЯГКОЕ предупреждение + логичная подсказка режима.
- Двойной режим («НОЧЬ ДЕНЬ 32») = ОШИБКА + автофикс с ВЫБОРОМ (оставить первый/второй), день сохранить.
- Два дня («НОЧЬ 32 33») = ОШИБКА + автофикс (оставить один).
- ФБ/ФЛЕШБЕК/ФФ (в номере «14-16-ФБ» или в тексте «ДЕНЬ . ФЛЕШБЕК») = авто special-день, не требовать номера.
- «УДАЛЕНА» — пропускать в днях/статистике.
- Будущая идея: экспорт не экспортирует УДАЛЕНА (зарегистрирована, не реализуется).

## ПАРСЕР
Понимать «режим+день» в грязных шапках: день+состав+тайминг+точка на одной строке
(«14-1. НАТ. … ДЕНЬ 32.  ОСИНА, ДИМКА (02:08)»), литерные/ФБ-номера («14-16-ФБ», «1.a»), дубли номеров.

## ПИСЬМО
- Авто-переход к составу ПОСЛЕ дня (не резать «32» в контент).
- SmartType рекомендует день: ДЕНЬ/УТРО/ВЕЧЕР→НОЧЬ = тот же; НОЧЬ→ДЕНЬ/УТРО = следующий; тот же режим = тот же день по умолч.; пропуск разрешён; автор подтверждает/правит; быстрые варианты: тот же / след. / флешбек / флешфорвард.
- RU↔EN: режим переводим, день сохраняем («ДЕНЬ 32»→«DAY 32»).
- Статистика режимов — из очищенного режима.

## UI
- Бейдж дня в навигаторе/карточках/каркасе; спец одним цветом.
- Фильтр/группировку по дню — ОТЛОЖИТЬ (идея I-…).

## СТАТИСТИКА
- Сценарных дней N, сцен по дням, флешбеки/флешфорварды; режимы без изменений.

## ПЕРЕНОС сцены
- Если день/режим вписываются в контекст — МОЛЧА.
- Если конфликт — диалог с ОБЯЗАТЕЛЬНОЙ рекомендацией:
  «привести к контексту (день+режим)» / «оставить как есть (скачок→special)» / «вручную»; превью; режим предлагается вместе с днём; автор решает.

## ПЕРЕСЧЁТ дней
- Сохраняет границы дней + спец; перенумеровывает normal подряд ПО СЕЗОНУ.
- ПРЕВЬЮ-таблица (сцена/было/станет); ДА применяет + ПЕРЕПИСЫВАЕТ токен дня в шапке; НЕТ — только правка.

## СТАБИЛЬНОСТЬ
- storyDay НЕ меняется при перенумерации сцен; меняется только через подтверждённый перенос/пересчёт.

## МОСТИКИ (потом, не сейчас)
- storyDay — ключ для костюма-дня/грима-дня/скрипт-супервайзера/2-го режиссёра.

## ПРАВИЛО ГРАНИЦЫ ДНЯ (подсказка и пересчёт)
- Внутри дня режимы УТРО→ДЕНЬ→ВЕЧЕР→НОЧЬ НЕ меняют день.
- Новый обычный день начинается при переходе НОЧЬ(или ВЕЧЕР прошлого дня)→УТРО/ДЕНЬ,
  ЛИБО когда автор явно задал больший номер (пропуск ночи разрешён).
- Спец-дни (0/−N/+N/Х/ФБ/ФФ) НЕ влияют на счётчик и НЕ являются границей обычного дня.
- Подсказка: текущий день = последний обычный день до точки; НОЧЬ→УТРО/ДЕНЬ предлагай +1;
  ДЕНЬ→НОЧЬ тот же; автор может изменить/пропустить.
- Пересчёт: граница = сцена, чей обычный день отличается от предыдущего обычного, ИЛИ
  режим-переход НОЧЬ→УТРО/ДЕНЬ. Сохраняем границы и спец; обычные дни перенумеровываем
  подряд 1..N по сезону; спец не трогаем; переписываем токен дня в шапке.

## ПРИМЕРЫ (вложены в тесты)
Шапки: «14-1. НАТ. УЛИЦЫ…. ДЕНЬ 32.  ОСИНА, ДИМКА (02:08)»; «14-52. ИНТ. …ДЕЖУРКА. 32  РОМА, КУРЬЕР (00:15)»;
«14-65-ФБ. … НОЧЬ 32 33 .»; «14-16-ФБ. … ДЕНЬ 0.»; «14-29. … ДЕНЬ НОЧЬ 32.»; «1-6-2. … ДЕНЬ Х .»;
«1-23. … ДЕНЬ . ФЛЕШБЕК»; «1.a. НАТ. … ДЕНЬ 1.»; «1-8-А. … (00:00) УДАЛЕНА»; дубль «1-13».

Перенос A: [1-1..1-5 ДЕНЬ 1, 1-6 НОЧЬ 1, 1-7 ДЕНЬ 2, 1-8 ДЕНЬ 2]; перенести 1-8 между 1-5 и 1-6 →
конфликт (день2 внутри дня1) → диалог: рекомендация ДЕНЬ 1 (или НОЧЬ 1) / оставить ДЕНЬ 2 (скачок) / вручную.

Перенос B: [1-1..1-4 ДЕНЬ 1, 1-5 ВЕЧЕР 1, 1-6 НОЧЬ 1, 1-7 УТРО 2, 1-8 УТРО 2]; перенести 1-8 между 1-5 и 1-6 →
режим УТРО не вписывается → диалог: ВЕЧЕР 1 / НОЧЬ 1 / оставить УТРО 2 (скачок) / вручную.

пагинация/авто-переход/SmartType не сломаны; базлайн цел; гейт зелёный.
