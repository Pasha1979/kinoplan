# Среда разработки: расширения редактора

Дата: 2026-11-23

## Редактор и CLI
- Редактор: Devin Desktop (команды `windsurf` в системе нет)
- CLI: `C:\Users\user\AppData\Local\Programs\Devin\bin\devin-desktop.cmd`
- Версия: 1.141.2

Команды: `<CLI> --install-extension <ID>`, `<CLI> --list-extensions --show-versions`.

## Инцидент: 429 при установке vitest.explorer
- Симптом: `Error while installing extension vitest.explorer: Server returned 429` (временный лимит магазина при подряд идущих установках).
- Решение: пауза ~2 минуты и повтор — установилось из магазина. Запасной путь (не понадобился): .vsix с open-vsx.org/api/vitest/explorer/latest -> `--install-extension <файл.vsix>`.
- Урок: при установке нескольких расширений подряд делать паузы; при 429 просто подождать и повторить.

## После установки
Ctrl+Shift+P -> Developer: Reload Window; проверить иконку Todo Tree в боковой панели.

## Коннекторы
- GitHub MCP: URL https://api.githubcopilot.com/mcp/ (http). Вход через device flow требует scopes `repo,read:user`: `devin.exe mcp login github --scopes repo,read:user`. Без явных scopes токен выходит с ошибкой `Insufficient scope` (инцидент 2026-11-23).
- Context7: stdio, `npx -y @upstash/context7-mcp`, работает без API-ключа (с лимитом).
- Конфиг: `%APPDATA%\Devin\mcp_config.json` (пользовательский уровень, действует на все проекты).
