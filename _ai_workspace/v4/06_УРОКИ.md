## Процесс (самое дорогое)

2. **L-41** — Скоуп-правило: точечные фиксы, не «улучшать» вне задачи
3. **L-36** — Никогда токены/секреты в репозитории
4. **L-42** — Диагностировать реальную причину, не гадать классами/фиксами
5. **L-60** — «Демоны» v3 описаны, но не реализованы — текст ≠ механизм

7. **L-62..65** — Автоматизируй рутину; атомарные задачи с критерием; самоконтроль системы; периодические аудиты

## Редактор/код
8. **L-30** — Никогда `\b` с кириллицей — lookaround-границы (ДЕНЬ↔DAY баг)
9. **L-31** — Граница сцены — массив + индексы, не позиции
10. **L-14** — Не комбинировать подходы в одном решении
11. **L-27** — Массивы всегда с дефолтом (пустой перекрывает default)

13. **L-17/18** — CSS: не ограничивать width при padding; центрирование width100%+center
14. Старые: cleanup для setTimeout/subscriptions; иммутабельность в reorder; валидация индексов
15. Хоткеи — event.code, не event.key (русская раскладка)

18. «Сохранено» только после реальной записи — flush, не таймер

20. Помощь/валидация — контекстная по вкладке, не общая
