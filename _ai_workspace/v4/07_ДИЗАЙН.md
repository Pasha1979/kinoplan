## Правила интерактивности (канон, 26.05.2026)

### Hover Lift — подъём при наведении
```
transition-all duration-200
hover:-translate-y-1        ← карточки (ProjectCard, карточки выбора)
hover:-translate-y-0.5      ← кнопки (CTA, «Новый проект», «Создать»)
active:translate-y-0        ← возврат при клике
```

### Hover Glow — усиление тени
```
hover:shadow-xl hover:shadow-[accentColor]/10-25
```
- Оранжевые кнопки: `hover:shadow-orange-500/40`
- Карточки сценария (индиго): `hover:shadow-[rgba(99,102,241,0.25)]`
- Карточки (зелёные): `hover:shadow-[rgba(16,185,129,0.2)]`

### Принцип
- **Карточки** — `hover:-translate-y-1` · **CTA** — `hover:-translate-y-0.5`
- **Сайдбар** — без подъёма, только цвет/фон · **Деструктивные** — без подъёма, только цвет

## Что добавлено в v5.0 (спринты 13–15.11)

### Редакционные статусы сцены (T-121/122)
- Бейдж статуса на карточке + выпадашка по клику и правому клику; цвет = цвет статуса (6 встроенных + свои)
- Точка статуса в SceneNavigator (вкладка Текст) — тот же паттерн выпадашки
- Модалка «Управление статусами»: ✏️ инлайн-правка (имя/цвет/вес), 🗑 с подтверждением и выбором судьбы сцен; встроенные — пометка «встроенный», без кнопок

### Фильтры-выпадашки доски (I-91/92/93)
- Тип сцены / серия / статус — выпадающие списки вместо строк чипов и пилюль (экономия места); активный фильтр виден на кнопке

### Валидация и готовность
- Правая панель — ТОЛЬКО на вкладке Текст; кнопка-тогл в шапке тоже только там

### Паттерны «ожидания»
- Заглушки-модули: оранжевый бейдж «Ожидается в следующем обновлении» + пояснение (Посерийник)
- «Заметки»/«Версии» в правой панели — «В разработке»

### Пагинация и экспорт
- Экран = бумага: marginTop-only модель, сведена к Word (T-92, 5/5 эталонов, разница 0)
- CONT'D / (ПРОДОЛЖЕНИЕ) декорацией на разрывах; @page в .doc

### Клавиатура и типографика
- Пресеты Enter (KinoPlan / Final Draft / КИТ) — селектор в шапке; Ctrl+Shift+S — новая сцена везде
- Авто-типографика (`--`→`—`, `"`→`«»`, `(з/к)`→`(З/К)`) — тогл ««»»
- Typewriter-режим — курсор по центру экрана

### Честность UI (спринт-2)
- Заглушки показывают «Скоро», без фейковых %; реальный % готовности только по живым данным
- Dev-инструменты («Настроить», конструктор раскладки) — под `import.meta.env.DEV`

### Умное управление (видимо в продукте — нет)
- STATUS-дашборд (02_СТАТУС автоген), SESSION_HANDOFF, CONTEXT_CHECKPOINT, brain:next/promote — процессные, не UI
