## 📚 БИБЛИЯ ПЕРСОНАЖЕЙ И ПОСЕРИЙНИК

### Библия персонажей

**Что это:** Документ с подробным описанием всех персонажей проекта. Позволяет сохранить целостность персонажей при смене сценаристов.

**Зачем нужна:**
- Сохраняет целостность персонажей при смене сценаристов
- Помогает съёмочной группе понять героев
- Проверка на понимание автором своих персонажей

**Обязательные поля:**
- Краткая характеристика (2-4 строчки) — тест на понимание
- Архетип, типаж, характер, манера поведения
- Взаимоотношения (конфликты, любовная линия, друзья, недруги)
- Мотивация, привычки, приметы
- Родственники (только если нужно для сюжета)
- Краткая история, загадочные события

**Чего НЕ нужно:**
- Детальное описание внешности (рост, вес, цвет волос)
- Описание одежды и мелочей (видно на экране)

**Фичи для КиноПлан:**
- Карточки персонажей с полями
- Связи между персонажами (визуальный граф)
- Фото-референсы для кастинга
- Поиск персонажей по характеристикам
- Экспорт/импорт библии

### Синопсис

**Что это:** Краткий пересказ сюжета от начала до конца (с развязкой). Пишется для профессионалов, без загадок.

**Структура:**
- Экспозиция — 25% объёма
- Завязка с поворотами — 50% объёма
- Кульминация и развязка — 25% объёма

**Что должно быть:**
- Описание местонахождения, времени
- Все ключевые фигуры и события
- Финал, разгадки загадок
- Мотивы героев

**Как писать:**
- Написан глазами главного героя
- Пропитан жанром и тональностью
- Конкретика, точные описания
- Простые предложения, короткие абзацы

**Фичи для КиноПлан:**
- Редактор синопсиса с подсказками
- Автоматический расчёт объёма частей
- Индикатор соблюдения структуры
- Шаблоны для разных жанров

### Посерийник (поэпизодник)

**Что это:** План сериала по сериям. Определяет последовательность сцен и эпизодов.

**Зачем нужен:**
- Определяет последовательность сцен и эпизодов
- Позволяет рассчитать финансовые затраты
- Является основой для написания сценария

**Фичи для КиноПлан:**
- Карточки серий с полями (номер, название, описание, сцены, хронометраж)
- Визуальный план серий (timeline)
- Связь с редактором (сцены переносятся в редактор)
- Статистика по сериям
- Drag and drop серий

### Архитектура интеграции

```
Библия персонажей
    ↓ (персонажи)
Синопсис
    ↓ (разбивка на серии)
Посерийник
    ↓ (сцены)
Редактор сценариев
```

### Поток работы сценариста

1. Создание проекта → Библия персонажей (разработка героев)
2. Синопсис → краткий пересказ сюжета
3. Посерийник → разбивка синопсиса на серии
4. Редактор → написание сцен по посерийнику
    ├── Либретто
    └── Экспорт: PDF / DOCX
```

**Типы данных (ScriptStore):**
- BreakdownCategory: cast, extras, props, costumes, locations, vehicles, sfx, stunts, vfx, notes
- Scene: id, projectId, number, type (INT/EXT/INT-EXT), location, timeOfDay, synopsis, pages, cast[], breakdownElements[], scriptText?, colorTag?, isOmitted, order
- Script: id, projectId, title, version, format (russian/hollywood), scenes[], characters[], createdAt, updatedAt
- Character: id, name (капслок), description?, sceneCount

**Редактор — блочные элементы (форматирование):**
- scene_header, action, character, dialog, parenthetical, transition
- Авто-переходы: Tab/Enter меняют тип блока
- Авто-форматирование: «инт.» → scene_header, капслок → character
- SmartType: автодополнение имён персонажей и локаций
- Российский формат: отступы по стандарту КИТ Сценариста

**Импорт / Экспорт:**
- PDF, DOCX (импорт/экспорт)
- FDX, Fountain (Фаза 2)
- Актёрская выборка PDF, Либретто PDF (экспорт)

**Что берём от конкурентов:**
- Авто-форматирование по Tab/Enter (Final Draft)
- SmartType — автодополнение (Final Draft)
- Revision Mode — цвета ревизий (Final Draft)
- Оба формата: Голливудский + Российский (Filmtoolz)
- Навигатор сцен (КИТ Сценарист)
- Карточки сцен на доске (КИТ Сценарист)
- Автосинопсис из текста сцен (КИТ Сценарист)
- Импорт DOCX/PDF с авто-парсингом (Filmtoolz)
- Два режима списка сцен: по нумерации / по локации (Filmtoolz)
- Breakdown Sheet — категории элементов на сцену (Movie Magic)
- Настраиваемые категории разбивки (Movie Magic)
- Либретто + актёрские выборки (Filmtoolz)

**Порядок реализации Фазы 1:**
1. ScriptStore — типы данных, Zustand стор с persist
2. Таб 2: Список сцен — ручное добавление сцен
3. Разбивка — Breakdown Sheet по сцене
4. Таб 1: Редактор — текстовый редактор с авто-форматированием
5. Импорт текста — вставка сценария → авто-парсинг сцен
6. Таб 3: Отчёты — актёрские выборки, экспорт PDF

**Лучшие идеи конкурентов для сценария:**
- Профессиональный редактор с форматированием ИНТ./ЭКСТ., кириллица, нумерация сцен (StudioBinder)
- Script Breakdown — тегирование элементов 1 кликом (StudioBinder)
- AI Script Breakdown — авто-тегирование (Filmustage, Фаза 4)
- Script Sides — автогенерация сайдов по актёру/дню (StudioBinder, Filmustage)
- AI Synopsis — автосинопсис сцены/сценария (Filmustage)
- Фильтрация по сериям в списке сцен (Filmtoolz)
- Быстрый поиск по сценам: по персонажу, объекту, ключевому слову (Filmtoolz)
- Два режима отображения сцен: по объектам или по нумерации (Filmtoolz)

#### 2. АВТО-ФОРМАТИРОВАНИЕ — Гибридный подход

**Решение:** Объединяем умное распознавание + ручное управление Tab/Enter

**Умное распознавание (по умолчанию):**
| Что пишет пользователь | Распознаётся как |
|------------------------|------------------|
| `ИНТ.` / `ЭКСТ.` / `ИНТ./ЭКСТ.` | Заголовок сцены |
| `НАПЛЫВ:` / `СМЕНА ПЛАНА:` | Переход |
| ВСЕ ЗАГЛАВНЫЕ (2+ слова) | Имя персонажа |
| Обычный текст после имени | Диалог |
| Текст в скобках `(взволнованно)` | Ремарка в диалоге |
| Текст без заглавных | Описание действия (ремарка) |

**Ручное управление (Tab/Enter):**
- **Tab** — переключить тип текущего абзаца циклически: `Заголовок → Ремарка → Персонаж → Диалог → Проходка → Ремарка`
- **Enter** в конце диалога → автоматически переход к ремарке (готовность к следующей сцене)
- **Ctrl+1..6** — быстрое переключение типа абзаца по номеру

### 📐 СТАНДАРТЫ ФОРМАТИРОВАНИЯ — Полная спецификация

**Решение:** ✅ Пользователь может выбирать формат (Голливудский / Российский / Пользовательский)

#### Голливудский формат (WGA стандарт)

**Шрифт:**
- Семейство: Courier или Courier New
- Размер: 12 pt
- Почему моноширинный: обеспечивает консистентность символов/слов/строк на странице → правило 1 страница = 1 минута

**Поля страницы:**
- Левое: 1.5 дюйма (3.81 см)
- Правое: 1 дюйм (2.54 см)
- Верхнее: 1 дюйм (2.54 см)
- Нижнее: 1 дюйм (2.54 см)

**Отступы элементов:**
- **Имя персонажа:** 3.7 дюйма от левого края (9.4 см), ALL CAPS
- **Диалог:** 2.5 дюйма от обоих краёв (6.35 см)
- **Ремарка:** 3.1 дюйма от левого края (7.87 см), не шире 2 дюймов

**Параметры страницы:**
- Макс: 54-55 строк на странице
- Нумерация: верхний правый угол, с точкой, первая страница без номера
- Титульная страница не считается

**Заголовки сцен:**
- ALL CAPS
- 3 части: INT./EXT. + локация + DAY/NIGHT
- Вторичные заголовки: только локация (например, BEDROOM после INT. HOUSE - DAY)

---

#### Российский формат (КИТ Сценарист стандарт)

**Шрифт:**
- Семейство: Courier New
- Размер: 12 pt
- Выравнивание: по левому краю
- ⚠️ Жирный, курсив, подчеркивание — НИКОГДА не используются

**Поля страницы:**
- Верхнее: 2.5 см
- Нижнее: 1.25 см
- Левое: 3.75 см

#### 9. СИСТЕМЫ ХРОНОМЕТРАЖА

**Решение:** ✅ Пользователь может выбирать систему расчёта

| Система | Принцип | Когда использовать |
|---------|---------|------------------|
| **Постраничный** | 1 страница = 1 минута (стандарт) | Стандартный сценарий, моноширинный шрифт |
| **Посимвольный** | N символов = 1 секунда | Нестандартное форматирование, проза |
| **Гибкий** | Комбинация методов | Длинные описания, необычная структура |
| **Ручной** | Пользователь задаёт время сцены | Известная длительность, музыкальные номера |

**Настройки проекта:**
```

                      [ ] 1 стр = 1 мин  [ ] ___ символов = 1 сек

**Расчёт для отдельной сцены:**
- Постраничный: `pages × 1 минута × жанровый_коэффициент`
- Посимвольный: `chars ÷ chars_per_second = секунды`
- Гибкий: алгоритм КИТ (учитывает тип блоков: заголовок, ремарка, диалог)

### 📊 ИССЛЕДОВАНИЕ СТАНДАРТОВ ХРОНОМЕТРАЖА

**Правило "1 страница = 1 минута" — миф или реальность?**

Исследование Stephen Follows (анализ 2,520 сценариев vs реальный хронометраж фильмов):

**Факты:**
- Среднее соотношение: **1 страница = 55 секунд** (не 1 минута!)
- Только **18.2%** сценариев попадают в диапазон 0.95-1.05
- Медиана: 119 страниц → 108 минут (11 страниц "лишних")
- Правило работает только для 1 из 5 сценариев

**Почему правило не работает:**
1. Сценарии длиннее фильмов (сцены вырезаются при монтаже)
2. Разные жанры — разные соотношения
3. Визуальные vs диалоговые жанры
4. Длинные/короткие сценарии — правило ломается на краях

**Жанровые коэффициенты (по данным исследования):**

| Жанр | Соотношение | 1 страница = | Объяснение |
|------|-------------|--------------|------------|
| **Мюзиклы** | 0.9 | 54 секунды | Музыкальные номера занимают экранное время без текста |
| **Военные** | 0.99 | 59.4 секунды | Длинные экшн-сцены, мало диалогов |
| **Драма** | ~1.0 | 60 секунд | Баланс диалогов и действия |
| **Комедия** | 1.15 | 52 секунды | Быстрые диалоги, много текста на секунду экранного времени |

**Вывод для КиноПлана:**
- Постраничный метод — базовый, но с жанровым коэффициентом
- По умолчанию: 1 страница = 55 секунд (реалистичнее)
- Пользователь может выбрать коэффициент по жанру
- Гибридный метод — наиболее точный для нестандартных форматов

#### 3. Влияние на ресурсы
```
Как изменения v4.0 повлияли на продакшен:
👥 Актёры: +2 новых персонажа (ИГОРЬ, МАРИНА)
🏢 Локации: +1 новая локация (ИНТ. РЕСТОРАН)
🚗 Транспорт: без изменений
💰 Бюджет: +~150,000 ₽ (новые локация + актёры)
📅 Расписание: +1 съёмочный день
```

#### 4. Активная версия драфта
- Выбор текущей версии для работы
- При смене версии → автоматическое обновление Breakdown, Stripboard, Вызывных
- Уведомление команды: «Сценарий обновлён до v4.0»

#### 10. Ментальные карты — Визуализация связей

**Что это (простыми словами):**
Ментальная карта — это схема, где в центре главная идея (например, название фильма), а от неё идут ветви с подпунктами (персонажи, локации, сюжетные линии). Это как дерево мыслей на экране.

**Как помогает сценаристу:**

1. **Визуализация связей** — видно как персонажи связаны между собой
   - Например: Иван → любит → Марину → работает с → Петром
   - Сразу видно кто с кем связан в сюжете

2. **Структура истории** — видна вся структура сюжета на одном экране
   - Акт 1 → Введение → Завязка
   - Акт 2 → Развитие → Кульминация
   - Акт 3 → Развязка → Финал

3. **Генерация идей** — свободное ассоциирование
   - Можно добавлять новые ветви и идеи
   - В отличие от линейного списка, можно свободно перемещаться между идеями

4. **Поиск пробелов** — видно чего не хватает
   - Например: есть персонаж, но нет его арки
   - Есть локация, но нет сцен с ней

### Фишки и фичи модуля сценария

#### Фаза 1 (минимальный MVP)

**1. Текстовый редактор с авто-форматированием**
- Авто-распознавание ИНТ./ЭКСТ. заголовков
- Авто-форматирование персонажей (ALL CAPS)
- Авто-форматирование диалогов и ремарок
- Настраиваемый алгоритм Tab/Enter
- Поддержка кириллицы
- Российский формат отступов
- Голливудский формат отступов

**2. Навигатор сцен (левая панель)**
- Список всех сцен с номерами
- Клик → переход к сцене
- Поиск по сценам
- Фильтрация по локации
- Фильтрация по персонажу
- Закладки на важные сцены (Bookmarking)

**3. Хронометраж в реальном времени**
- Постраничный метод (1 страница = 55 секунд)
- Жанровый коэффициент (мюзикл 0.9, комедия 1.15, драма 1.0)
- Отображение в верхней панели

**4. Title Page Generator**
- Автоматическая генерация титульной страницы
- Поля: название, авторы, контакт, логлайн, копирайт
- Включается в экспорт PDF

**5. Format Assistant**
- Автоматическая проверка форматирования
- Подсветка ошибок
- Предложение автоисправления

**6. Bookmarking**
- Закладки на важные сцены
- Цветовые метки (красная, жёлтая, синяя)
- Быстрый доступ к закладкам

---

#### Фаза 2 (расширение)

**7. ScriptNotes — заметки к строкам**
- Заметки к конкретным строкам (не только к сценам)
- Маркеры заметок в тексте
- Отображение в правой панели
- Фильтрация по автору

**8. Scene Properties — свойства сцены**
- Дата съёмки
- Номер съёмочного дня
- Приоритет съёмки (высокий/средний/низкий)
- Статус (не запланирована/запланирована/снята)
- Заметки для съёмочной группы

**9. Проверка орфографии**
- Встроенная проверка русского языка
- Встроенная проверка английского языка
- Подсветка ошибок
- Предложения исправлений

**10. Версионность сценариев (The Drafts)**
- Сохранение драфтов (Черновик 1, Черновик 2, Съёмочный)
- Список всех версий в правой панели
- Выбор активной версии
- Откат к старой версии

**11. Вкладка «Карточки»**
- Визуальная доска с карточками сцен
- Drag & Drop для перестановки сцен
- Цветовая кодировка по типу сцены
- Режим разбивки (Breakdown)

**12. Вкладка «Разработка»**
- Персонажи: карточки с описанием, подсчёт сцен
- Локации: карточки с описанием, фото
- Мир: описание мира проекта
- Хронология: временная линия событий
- Темы: ключевые темы истории
- Референсы: материалы (фото, ссылки)

**13. Вкладка «Статистика»**
- Общий хронометраж
- Количество сцен, персонажей, локаций
- График активности персонажей
- Баланс ИНТ/ЭКСТ
- Распределение по времени суток
- Экспорт отчёта

**14. Вкладка «План»**
- План работы сценариста
- Дедлайны этапов (логлайн, synopsis, beat plan, драфты)
- Прогресс по этапам
- Связь с календарём проекта

#### Фаза 3 (важные)

**15. Шаблоны сценариев**
- Готовые пресеты: художественный фильм, сериал, рекламный ролик, документальный
- Автоматические настройки формата, хронометража, жанра

**16. Ментальные карты**
- Визуализация связей между персонажами
- Визуализация связей между локациями

- Авто-расположение
- Интеграция: персонажи из карты → автоматически в разделе «Персонажи»

**17. Автосохранение в облако (опционально)**
- Local-First приоритет
- Опциональная синхронизация с WebDAV (Яндекс.Диск, VK Cloud)

- Резервное копирование

### Уникальные преимущества КиноПлан

6. **Российский стандарт** — отечественный формат (КИТ Сценарист) + голливудский

7. **Бесплатно** — или разумная цена по сравнению с конкурентами

8. **Версионность с влиянием на ресурсы** — видно как изменения сценария влияют на бюджет и расписание
