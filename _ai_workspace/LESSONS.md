- **Почему это случилось:** [причина]
- **Как избежать в будущем:** [решение]

### Урок 1 (2026-06-12)
- **Дата:** 2026-06-12
- **Что пошло не так:** Папка .windsurf лежала внутри _ai_workspace и Windsurf её не видел
- **Почему это случилось:** Windsurf ищет конфигурацию только в корне проекта
- **Как избежать в будущем:** Папка .windsurf должна быть всегда в корне, а в .windsurfrules указывать пути к памяти

### Урок 2 (2026-06-13)
- **Дата:** 2026-06-13
- **Что пошло не так:** Текст сценария хранился в localStorage (draftKey), а метаданные — в Zustand. При смене устройства текст пропадал
- **Почему это случилось:** localStorage — ненадёжное хранилище (очистка кэша, другой браузер, другой компьютер)
- **Как избежать в будущем:** Единый источник правды — Zustand persist. Всё в одном месте, sync-ready для PouchDB

### Урок 3 (2026-06-13)
- **Дата:** 2026-06-13
- **Что пошло не так:** Все сцены всех серий лежали в одном массиве scriptStore.scenes. Перестановка ломала номера, статистика считалась по всем сериям
- **Почему это случилось:** Архитектура не учитывала, что для сценариста каждая серия = отдельный документ
- **Как избежать в будущем:** Каждая серия — отдельный Script с episodeNumber. Сцены изолированы, переключение через currentScriptId

### Урок 4 (2026-06-13)
- **Дата:** 2026-06-13
- **Что пошло не так:** Пользователь не сразу понял разницу между вариантами решения (А, Б, В)
- **Почему это случилось:** Слишком технические объяснения без привязки к пользовательскому опыту
- **Как избежать в будущем:** Всегда начинать с «Что это значит для сценариста», потом технические детали. Таблица «Было → Стало» работает лучше всего
