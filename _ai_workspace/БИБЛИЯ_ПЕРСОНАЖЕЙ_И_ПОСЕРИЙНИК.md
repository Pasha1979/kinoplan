## 1. Библия персонажей

### Что это такое
Библия персонажей — это документ с подробным описанием всех персонажей проекта. Позволяет сохранить целостность персонажей при смене сценаристов и помогает съёмочной группе лучше понять героев.

### Зачем нужна
- Сохраняет целостность персонажей при смене сценаристов
- Помогает съёмочной группе понять героев
- Позволяет полностью погрузиться в созданный мир
- Является проверкой на понимание автором своих персонажей

### Что должно быть в библии персонажей

#### Обязательные поля:
- **Краткая характеристика** — 2-4 строчки, тест на понимание персонажа
- **Архетип** — общий типаж
- **Характер** — манера поведения
- **Взаимоотношения** — с другими персонажами (конфликты, любовная линия, друзья, недруги)
- **Мотивация** — что движет героем
- **Привычки и приметы** — особые черты
- **Родственники** — родители, дети (только если нужно для сюжета)
- **Краткая история** — возможные загадочные события

#### Чего НЕ нужно:
- Детальное описание внешности (рост, вес, цвет волос)
- Описание одежды и мелочей
- Всё это видно на экране, не влияет на сюжет

### Как правильно составлять
1. Сначала создать общую канву, графический набросок
2. Дополнять по мере развития событий
3. Не пытаться объять необъятное сразу
4. Большие полотна текста плохо воспринимаются
5. Тест на понимание: если можно охарактеризовать в 2-4 строчках — профессионал

### Фичи для КиноПлан

#### Вкладка "БИБЛИЯ ПЕРСОНАЖЕЙ":
- **Карточки персонажей** с полями:
  - Имя
  - Краткая характеристика (2-4 строчки)
  - Архетип/типаж
  - Характер, манера поведения
  - Мотивация
  - Привычки и приметы
  - Взаимоотношения (связи с другими персонажами)
  - Родственники
  - Краткая история
- **Связи между персонажами**:
  - Друзья/враги
  - Любовная линия
  - Конфликты
  - Визуальный граф связей
- **Фото-референсы** для кастинга
- **Поиск персонажей** по характеристикам
- **Экспорт/импорт** библии

## 2. Синопсис

### Что это такое
Синопсис — это краткий пересказ сюжета от начала до конца (с развязкой). Пишется для профессионалов, без загадок и интриги.

### Зачем нужен
- Промежуточный этап между идеей (логлайном) и поэпизодником
- Входит в сценарную заявку
- На его основе пишутся бит шит и поэпизодник
- Проверка на качество истории

### Структура синопсиса
- **Экспозиция** — до 25% объёма
- **Завязка с поворотами сюжета** — 50% объёма
- **Кульминация и развязка** — 25% объёма

### Что должно быть в синопсисе
- Описание местонахождения, времени
- Все ключевые фигуры и события
- Финал, разгадки загадок
- Мотивы героев
- Всё раскрывается и детализируется (без загадок)

### Как правильно писать
- Написан глазами главного героя
- Пропитан жанром и тональностью картины
- Конкретика, точные описания, без размытых фраз
- Простые предложения, короткие абзацы
- Должен быть понятен даже школьнику
- Сюжет должен "цеплять", включать воображение

### Фичи для КиноПлан

#### Вкладка "СИНОПСИС":
- **Редактор синопсиса** с подсказками:
  - Автоматический расчёт объёма частей (экспозиция/завязка/кульминация)
  - Индикатор соблюдения структуры (25%/50%/25%)
  - Подсказки по жанровой тональности
- **Шаблоны синопсиса** для разных жанров
- **Экспорт/импорт** синопсиса
- **Связь с посерийником** — синопсис разбивается на серии

## 3. Посерийник (поэпизодник)

### Что это такое
Посерийник (поэпизодник) — план сериала по сериям. Определяет последовательность сцен и эпизодов.

### Зачем нужен
- Определяет последовательность сцен и эпизодов
- Позволяет рассчитать финансовые затраты
- Является основой для написания сценария

### Что должно быть в посерийнике
- Описание содержания каждой серии
- Последовательность сцен в серии
- Связь между сериями

### Фичи для КиноПлан

#### Вкладка "ПОСЕРИЙНИК":
- **Карточки серий** с полями:
  - Номер серии
  - Название серии
  - Краткое описание
  - Список сцен (привязка к редактору)
  - Хронометраж серии
  - Персонажи в серии
- **Визуальный план серий** (timeline)
- **Связь с редактором** — сцены из посерийника переносятся в редактор
- **Статистика по сериям**:
  - Хронометраж
  - Количество сцен
  - Персонажи
- **Drag and drop** серий для перестановки
- **Экспорт/импорт** посерийника

## 4. Архитектура интеграции

### Связь между компонентами

```
Библия персонажей
    ↓ (персонажи)
Синопсис
    ↓ (разбивка на серии)
Посерийник
    ↓ (сцены)
Редактор сценариев
```

### Поток работы сценариста

1. **Создание проекта** → Библия персонажей (разработка героев)
2. **Синопсис** → краткий пересказ сюжета
3. **Посерийник** → разбивка синопсиса на серии
4. **Редактор** → написание сцен по посерийнику

### Хранение данных

- **Библия персонажей**: localStorage / SQLite
- **Синопсис**: localStorage / SQLite
- **Посерийник**: localStorage / SQLite
- **Связи**: через ID персонажей и серий
