## 📐 МЕТОДОЛОГИЯ РАЗРАБОТКИ KINOPLAN

### Основной подход:
1. **Модульная разработка с заглушками**
   - Создаем главную страницу с заглушками всех модулей
   - Реализуем модули по одному
   - Заглушки постепенно заменяются на функционал
   - **Заглушки НЕ удаляются, пока модуль не реализован**

2. **Два подмодуля "Сценарий":**
   - А. Создание сценария с нуля (для сценаристов) — В ПРИОРИТЕТЕ
   - Б. Загрузка готовых сценариев — после завершения редактора

3. **Взаимосвязь модулей:**
   - Все модули будут связаны между собой
   - Информация из одного модуля влияет на другой
   - Пример: Сценарий → Продакшен → Планирование
   - Связывание начинается при реализации соответствующих модулей

4. **Итеративное улучшение:**
   - Во время реализации добавляются идеи/фичи/визуал
   - Это СРАЗУ учитывается в плане
   - Движение от модуля к модулю
   - Иногда возврат к "завершенным" модулям для доработки

### Текущий фокус:
**Модуль "Сценарий" → Подмодуль А: Создание сценария с нуля (редактор)**

### Правила для Windsurf:
1. При упоминании новой идеи/фичи/визуала → НЕМЕДЛЕННО добавить в `💡_ЗАДЕЛЫ_И_ИДЕИ.md`
2. При изменении приоритетов → ОБНОВИТЬ `ПЛАН_РАБОТ.md`
3. При завершении подмодуля → перейти к следующему или вернуться к доработке
4. При связывании модулей → зафиксировать в плане какие данные передаются
5. Заглушки НЕ удалять, пока модуль не реализован

## 🚀 Git Workflow (после каждого шага)

### После каждого завершённого шага
```bash
# 1. Добавить все изменения
git add .

# 2. Commit с описанием изменений
git commit -m "описание"

# 3. Push в main (синхронизация с GitHub)
git push origin main

# 4. Vercel деплой запустится автоматически
```

### Проверка
- [ ] GitHub обновлён: https://github.com/Pasha1979/kinoplan
- [ ] Vercel пересобрал: https://kinoplan.vercel.app
- [ ] Локальный сервер работает: http://localhost:5173/

**Команды (PowerShell):**
```powershell
$env:PATH = "C:\Program Files\nodejs;" + $env:PATH
git add .
git commit -m "описание"
git push
```

## 🔄 Vercel CI/CD

### Автоматический деплой
1. При `git push` в `main` → Vercel запускает сборку
2. Проверка логов: https://vercel.com/pasha1979/kinoplan
3. Статусы:
   - ✅ **Ready** — успешно
   - ❌ **Failed** — ошибка сборки
   - 🔄 **Building** — в процессе

### Ручной redeploy (если кэш)
1. Открыть https://vercel.com/dashboard
2. Найти проект kinoplan
3. Нажать "Redeploy without cache"
