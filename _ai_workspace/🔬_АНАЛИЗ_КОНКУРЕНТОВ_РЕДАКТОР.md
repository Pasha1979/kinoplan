## 🎯 КЛЮЧЕВЫЕ МЕХАНИКИ ПО КОНКУРЕНТАМ

### **КИТ Сценарист** (Российский стандарт)

```
📝 ШАПКА СЦЕНЫ:
Начало строки + «и» → подсказка «ИНТ.»
Начало строки + «н» → подсказка «НАТ.»
После ИНТ./НАТ. → подсказка ранее введённых локаций
При нажатии «—» (тире) или Tab → подсказка времени (УТРО/ДЕНЬ/ВЕЧЕР/НОЧЬ)
Первые буквы времени → фильтрация подсказок

✨ ОСОБЕННОСТИ:
- Сохранение пользовательского времени/места для проекта
- Автоподстановка через Tab/Enter
- Esc для отказа
- Можно отключить в настройках
```

### **Filmtoolz** (Импорт-ориентированный)

```
📝 РАСПОЗНАВАНИЕ ПО ОТСТУПАМ:

Пустая строка + текст = ДЕЙСТВИЕ (action)
Пустая строка + КАПСЛОК + следующая строка = ПЕРСОНАЖ
Без пустой строки после Персонажа = ДИАЛОГ
Скобки без пустой строки = РЕМАРКА

⚠️ ОШИБКИ РАСПОЗНАВАНИЯ:
- Любой текст ЗАГЛАВНЫМИ + следующая строка = Персонаж
- Любой текст между пустыми строками = Действие
- После Персонажа пустая строка = Действие (ошибка)
- Перед Ремаркой/Диалогом пустая строка = Действие (ошибка)

🛠️ ИНСТРУМЕНТЫ:
Кнопка «W» — режим сохранения форматирования Word
Кнопка «F» — автоформатирование (разовое)
Ручное назначение стиля через панель
```

### **Final Draft** (Голливудский стандарт)

```
📝 SMARTTYPE — ГЛАВНАЯ ФИШКА:

При наборе в Scene Heading:
«I» или «E» → подсказка INT./EXT.
Tab после INT/EXT → переход к Location
При наборе Location → подсказка из базы
Tab после Location → подсказка времени

📚 АВТОСОЗДАНИЕ БАЗ:
- SmartType создаёт списки автоматически
- Персонажи, локации, время, переходы
- Подсказки при наборе любых первых букв
- Command/Ctrl + 3 → список персонажей

🎭 ПЕРЕХОДЫ МЕЖДУ ЭЛЕМЕНТАМИ:
Tab на Character → Parenthetical (ремарка)
Tab после Character cue → Dialogue
Insert Character → автоматически создаёт Dialogue

🎨 НАСТРОЙКА SMARTTYPE:
- Автоматическое угадывание следующего персонажа
- Tab переход к Character Extension (V.O., O.S.)
- Настройка порядка списков
- Цвета подсказок
- Сортировка по количеству диалогов
```

## 🧩 ГИБРИДНАЯ МОДЕЛЬ ДЛЯ КИНОПЛАН

### **Фаза 1: Шапка сцены (сейчас)**

```
✅ РЕАЛИЗОВАТЬ:

1. РАСПОЗНАВАНИЕ ПО МАРКЕРАМ (как КИТ + Final Draft)
   - Начало строки + «И» → подсказка «ИНТ.»
   - Начало строки + «Э» → подсказка «ЭКСТ.»
   - Начало строки + «IN» → подсказка «INT.»
   - Начало строки + «EX» → подсказка «EXT.»
   - Если уже scene_header — не меняем тип при редактировании!

2. ПОДСКАЗКИ БЕЗ ВМЕШАТЕЛЬСТВА (как Final Draft SmartType)
   - Подсказка появляется, но не вставляется автоматически
   - Tab/Enter — принять подсказку
   - Esc — отказаться и писать дальше
   - Пробел/другие клавиши — просто продолжить набор

3. АВТО-СОХРАНЕНИЕ ЛОКАЦИЙ (как КИТ + Final Draft)
   - Каждая новая локация сохраняется в проект
   - При наборе после ИНТ./ЭКСТ. → подсказка из базы

4. АВТО-ПОДСТАНОВКА ВРЕМЕНИ (как КИТ)
   - При наборе «—» (тире) или Tab после локации
   - Подсказки: УТРО, ДЕНЬ, ВЕЧЕР, НОЧЬ
   - Фильтрация по первым буквам

5. РУЧНОЕ ПЕРЕКЛЮЧЕНИЕ (как Filmtoolz)
   - Кнопка переключения типа блока
   - Не меняем автоматически при редактировании!
```

### **Фаза 2: Полный редактор (будущее)**

```
⏳ ЗАПЛАНИРОВАНО:

- Справочник персонажей (как КИТ)
- Справочник локаций с описаниями
- Справочник времени суток + пользовательские
- Участники сцены через запятую
- Кнопка автоформатирования «F» (как Filmtoolz)
- SmartType для всех элементов (как Final Draft)
- Переходы Tab между элементами
- Ремарки на Tab от персонажа
- Настройки автоформатирования
```

## 🚨 КРИТИЧЕСКИЕ ПРАВИЛА ДЛЯ НАШЕГО РЕДАКТОРА

### **Правило 1: НЕ МЕШАТЬ АВТОРУ**
```
❌ ЗАПРЕЩЕНО:
- Автоматическая замена текста без подтверждения
- Изменение типа блока при редактировании текста
- Блокировка пробелов или других символов
- Принудительное форматирование

✅ РАЗРЕШЕНО:
- Показывать подсказку — автор сам решает
- Tab/Enter — принять подсказку
- Esc — отказаться
- Пробел/буквы — продолжить писать
```

### **Правило 2: ТИП БЛОКА = ВЫБОР АВТОРА**
```
- Тип определяется ПРИ СОЗДАНИИ блока
- При редактировании тип НЕ меняется автоматически
- Тип меняется ТОЛЬКО явно (Tab или кнопка)
- Шапка сцены остаётся шапкой пока автор не скажет Tab
```

### **Правило 3: SMARTTYPE = ПОМОЩНИК**
```
- Подсказки появляются при совпадении первых букв
- Подсказки из базы проекта + стандартные
- Не обязательно принимать — можно писать своё
- База пополняется автоматически
```

## 🎬 ПРИМЕР РАБОТЫ (целевой)

```
1. Пустой блок типа scene_header
   ↓
2. Автор пишет: «Э»
   ↓
3. ПОЯВЛЯЕТСЯ подсказка: [ЭКСТ.]
   ↓
4. Автор нажимает Tab → текст: «ЭКСТ. » (с пробелом)
   ИЛИ автор пишет дальше «КСТ. УЛИЦА» (игнорирует подсказку)
   ↓
5. После «ЭКСТ. » автор пишет «У»
   ↓
6. ПОЯВЛЯЕТСЯ подсказка: [УЛИЦА] [УНИВЕРСИТЕТ] (из базы)
   ↓
7. Автор выбирает или пишет своё
   ↓
8. После локации нажимает Tab или «—»
   ↓
9. ПОЯВЛЯЕТСЯ подсказка: [ДЕНЬ] [НОЧЬ] [УТРО] [ВЕЧЕР]
   ↓
10. Автор выбирает или пишет «ДЕНЬ 1»
   ↓
11. Нажимает Tab → новый блок action (или character)
```
