# 🤖 АКТИВНЫЙ АССИСТЕНТ — Интеллектуальные подсказки

> **Назначение:** Система ПРОАКТИВНЫХ напоминаний, валидации и рекомендаций.
> 
> **Принцип:** Не ждать пока AI прочтёт файлы — СИСТЕМА ПРОАКТИВНО напоминает.

---

## 🎯 ЗАДАЧИ СИСТЕМЫ

1. **Lesson Matching** — автоматический поиск релевантных уроков
2. **Plan Validation** — проверка действий против плана
3. **Memory Triggers** — автоматическое обновление памяти
4. **Next Steps Recommender** — предложение следующих шагов

---

## 📚 LESSON MATCHING (автоматические подсказки)

### Правила matching:

**Перед действием:**
1. Анализировать контекст действия (какие файлы меняются, какая операция)
2. Искать релевантные уроки в `LESSONS_LEARNED.md`
3. Предложить 1-3 релевантных урока

**Примеры:**
- Изменяю `tsx` файл → предложить урок про TypeScript проверки
- Коммит → предложить урок про Git workflow
- Добавляю секрет → предложить урок про GitHub Secret Blocking

### Формат предложения:
```
🔔 СООБЩЕНИЕ: [Тема]

Релевантные уроки:
- Урок N: [Название] — [Решение]
```

---

## ✅ PLAN VALIDATION (валидация логики)

### Правила валидации:

**Перед началом задачи:**
1. Проверить задачу против `ПЛАН_РАБОТ.md`
2. Если задача не в текущем приоритете → предупредить
3. Если задача пропускает шаг → предупредить

**Примеры:**
- Начинаю задачу P2 → предупредить "есть не завершённые P0 задачи"
- Пропускаю тестирование → предупредить "обязательный шаг"

### Формат предупреждения:
```
⚠️ ПРЕДУПРЕЖДЕНИЕ: [Тема]

Вы нарушаете логику разработки:
- [Причина 1]
- [Причина 2]

Продолжить? (да/нет/обсудить)
```

---

## 🧠 MEMORY TRIGGERS (автообновление памяти)

### Правила триггеров:

**После завершения задачи:**
1. Автоматически обновить `📊_ТЕКУЩИЙ_СТАТУС.md`
2. Автоматически предложить обновить `ПЛАН_РАБОТ.md`
3. Если была ошибка → предложить добавить урок

**Формат триггера:**
```
🔄 ТРИГГЕР: Задача завершена

Автоматически обновлено:
- 📊_ТЕКУЩИЙ_СТАТУС.md (прогресс)

Предлагаю:
- [ ] Обновить ПЛАН_РАБОТ.md (приоритеты)
- [ ] Добавить урок в LESSONS_LEARNED.md (если была ошибка)
```

---

## 🎯 NEXT STEPS RECOMMENDER (предложение шагов)

### Правила рекомендаций:

**После завершения задачи:**
1. Анализировать `ПЛАН_РАБОТ.md`
2. Найти топ-3 задачи по приоритету
3. Предложить следующую задачу

**Формат рекомендации:**
```
🎯 РЕКОМЕНДАЦИЯ: Следующие шаги

На основе текущего прогресса рекомендую:
1. [Задача 1] — [Причина]
2. [Задача 2] — [Причина]
3. [Задача 3] — [Причина]

Выбери задачу или предложи свою.
```

## 🔧 ИНТЕГРАЦИЯ

### Где вызывать:

2. Next Steps Recommender → предложить следующие шаги

```

Конец сессии
```
