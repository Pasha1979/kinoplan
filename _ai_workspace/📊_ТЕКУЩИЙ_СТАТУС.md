## 📋 Статус по подмодулю «Сценарист»

### Готово (✅)
1. **Навигатор по сценам (SceneNavigator)** — отображение списка сцен, переход по ним
2. **Базовый редактор с форматированием (ScriptEditor)** — ввод текста с типами блоков
3. **Титульный лист (TitlePageEditor)** — заглушка, форма настроек
4. **Формат-помощник (FormatAssistant)** — типы блоков: scene_header, action, character, dialog, parenthetical, transition
5. **Автонумерация сцен** — пересчёт номеров при добавлении, поддержка сериалов (1-5) и букв (1-5-А)
6. **SmartType для шапки сцены** — ВСЁ РАБОТАЕТ!
   - ИНТ./ЭКСТ. подсказки (только в шапке, не мешают в диалогах)
   - Локации (КВАРТИРА, УЛИЦА, ОФИС) с фильтрацией
   - Время (ДЕНЬ., НОЧЬ., УТРО., ВЕЧЕР.) с точкой
   - Автоперенос курсора после времени на новую строку
   - Участники сцены — подсказки персонажей на второй строке
   - Авто-запятая после имени
   - Tab/Enter — применить, Esc — закрыть, ↑↓ — навигация
7. **Правильное форматирование Russian/Hollywood**
   - Russian: Character 6.75cm center, Dialog 3.75cm/3.75cm
   - Hollywood: Character 9.3cm left, Dialog 6.35cm/2.5cm
   - Переключение RU/EN работает корректно

### Добавлено в сессии 01-02.06.2026 (✅)
8. **Навигатор сцен — полный парсинг:**
   - Бейдж ИНТ (фиолетовый) / ЭКСТ (зелёный) / ИНТ-ЭКСТ (оранжевый)
   - Иконки времени ☀️🌙🌅🌆 (ДЕНЬ/НОЧЬ/УТРО/ВЕЧЕР/РАССВЕТ/ЗАКАТ)
   - Персонажи из `sceneCast` — синие таблетки (до 3 + счётчик)
   - Реальный подсчёт страниц (charCount / 1800)
   - Парсинг времени через точку без тире (КВАРТИРА. ДЕНЬ.)
   - Фильтры: Все / ИНТ / ЭКСТ
9. **Серии (сериал) — каждая серия = свой черновик:**
   - draftKey: `kinoplan_draft_${projectId}_s${N}`
   - Переключение серии → автозагрузка нужного черновика
   - Кастомный дропдаун с тёмной темой вместо нативного select
10. **Хронометраж в шапке редактора:**
    - `X.X стр. ≈ Y мин` в реальном времени
    - Формула: totalPages × 55 сек × genreCoefficient
    - onStatsChange теперь реально вызывается
