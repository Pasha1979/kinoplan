# 🧠 SMART PRIORITIES — Умная приоритезация

> **Назначение:** Автоматическое изменение приоритетов по контексту

---

## 🎯 ПРИНЦИП

План всегда актуален — приоритеты меняются автоматически по контексту.

---

## 📚 ПРАВИЛА ПРИОРИТЕЗАЦИИ

### Правило 1: Блокировка P0
**Когда:** P0 задача блокирует P1
**Действие:** Поднять P1 до P0
**Пример:** Если P0-5 блокирует P1-6 → P1-6 становится P0

---

### Правило 2: Запрос пользователя
**Когда:** Пользователь просит задачу
**Действие:** Поднять приоритет задачи
**Пример:** Пользователь: "Сделай Shift+Enter" → P1-6 становится P0

---

### Правило 3: Обнаружен баг
**Когда:** Обнаружен критический баг
**Действие:** Сделать задачу P0
**Пример:** Баг в page breaks → становится P0

---

### Правило 4: Зависимость
**Когда:** Задача B зависит от незавершённой задачи A
**Действие:** Поднять задачу A
**Пример:** P1-7 зависит от P0-5 → P0-5 поднимается

---

## 🔍 АЛГОРИТМ

```markdown
При изменении контекста:
1. Проверить блокировки
2. Проверить запросы пользователя
3. Проверить баги
4. Проверить зависимости
5. Обновить приоритеты в ПЛАН_РАБОТ.md
6. Сообщить пользователю
```

---

## 🚀 ИНТЕГРАЦИЯ

```markdown
После каждого действия:
- Проверить приоритеты
- Обновить план
- Сообщить об изменениях
```
