# 🔐 TOKEN STORAGE — Безопасное хранение токена

> **Назначение:** Токен Vercel хранится отдельно от кода и передаётся AI между сессиями

---

## ⚠️ ПРАВИЛА БЕЗОПАСНОСТИ

1. **НИКОГДА не коммитить токен в код**
2. **НИКОГДА не сохранять токен в файлах, которые коммитятся**
3. **Токен хранится в .env файле (в .gitignore)**
4. **Токен передаётся AI при восстановлении контекста**

---

## 📁 ГДЕ ХРАНИТЬСЯ ТОКЕН

### Файл: `.env` (не коммитится)
```
VERCEL_TOKEN=<токен от пользователя>
```

### .gitignore (уже должен быть)
```
.env
.env.local
.env.*.local
```

---

## 🔄 КАК ИСПОЛЬЗОВАТЬ

### При коммите/пуше:
1. Прочитать токен из `.env`
2. Использовать в команде: `npx vercel ls --token=$VERCEL_TOKEN`
3. НЕ коммитить токен в код

### При восстановлении контекста:
1. Прочитать токен из `.env`
2. Сохранить в память AI для использования в этой сессии
3. Использовать для всех Vercel команд

---

## 🚨 ЕСЛИ ТОКЕН ПОТЕРЯН

1. Попросить пользователя предоставить токен
2. Создать/обновить `.env` файл
3. НЕ коммитить этот файл
