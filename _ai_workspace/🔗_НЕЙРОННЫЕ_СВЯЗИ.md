# 🔗 НЕЙРОННЫЕ СВЯЗИ — Карта связей _ai_workspace

> **Назначение:** Визуальная карта связей между файлами умного управления.
>
> **Правило:** При изменении файла ОБЯЗАТЕЛЬНО обновляй связанные файлы.

🔗 НЕЙРОННЫЕ СВЯЗИ:
* Зависит от: все файлы `_ai_workspace`
* Обновляет при изменении: (ничего, это справочник)

---

## 🗺️ КАРТА СВЯЗЕЙ

### Уровень 1 — Управление (входные точки)

```
🧠_МОЗГ_ПРОЕКТА.md (главная входная точка)
    ├──→ 📊_ТЕКУЩИЙ_СТАТУС.md
    ├──→ 🧠_SESSION_CONTEXT.md
    ├──→ 📈_МЕТРИКИ_ПРОГРЕССА.md
    ├──→ LESSONS_LEARNED.md
    └──→ ARCHITECTURE_GUARDIAN.md

🧠_SESSION_CONTEXT.md (контекст сессии)
    ├──→ 📊_ТЕКУЩИЙ_СТАТУС.md
    ├──→ 📝_DIALOG_HISTORY.md (при потере контекста)
    └──→ 📈_МЕТРИКИ_ПРОГРЕССА.md
```

### Уровень 2 — Планирование и идеи

```
ПЛАН_РАБОТ.md (очередь задач P0>P1>P2)
    ├──→ 📊_ТЕКУЩИЙ_СТАТУС.md
    └──→ ИДЕИ_МОДУЛЬ_СЦЕНАРИЙ.md (чеклист модуля)

💡_IDEA_MANAGER.md (процесс работы с идеями)
    ├──→ 💡_ЗАДЕЛЫ_ИДЕИ.md (хранилище идей)
    └──→ ПЛАН_РАБОТ.md (при переносе идеи в план)

💡_ЗАДЕЛЫ_ИДЕИ.md
    ├──→ ПЛАН_РАБОТ.md
    └──→ 📈_МЕТРИКИ_ПРОГРЕССА.md
```

### Уровень 3 — Архитектура и правила

```
ARCHITECTURE_GUARDIAN.md
    ├──→ ПРАВИЛА_АРХИТЕКТУРЫ.md
    └──→ .windsurfrules (правила сессии)

.windsurfrules (корень, правила AI)
    ├──→ 🧠_МОЗГ_ПРОЕКТА.md
    ├──→ 📊_ТЕКУЩИЙ_СТАТУС.md
    └──→ LESSONS_LEARNED.md
```

### Уровень 4 — Журналы и справочники

```
LESSONS_LEARNED.md → 🤖_АКТИВНЫЙ_АССИСТЕНТ.md (lesson matching)
🏆_ЖУРНАЛ_УСПЕХОВ.md → 🧠_МОЗГ_ПРОЕКТА.md
🌟_PROJECT_EVOLUTION.md → 🧠_МОЗГ_ПРОЕКТА.md
📚_КАТАЛОГ_ФАЙЛОВ.md → (справочник, обновляется при добавлении файлов)
```

## 📋 ТАБЛИЦА «ИЗМЕНИЛ → ОБНОВИ»

| Если изменил | Обязательно обнови |
|---|---|
| `🧠_МОЗГ_ПРОЕКТА.md` | `📊_ТЕКУЩИЙ_СТАТУС.md`, `📈_МЕТРИКИ_ПРОГРЕССА.md` |
| `🧠_SESSION_CONTEXT.md` | `📊_ТЕКУЩИЙ_СТАТУС.md` (итоги сессии) |
| `📊_ТЕКУЩИЙ_СТАТУС.md` | `📈_МЕТРИКИ_ПРОГРЕССА.md` |
| `💡_ЗАДЕЛЫ_ИДЕИ.md` | `📈_МЕТРИКИ_ПРОГРЕССА.md` (счётчики идей) |
| `ПЛАН_РАБОТ.md` | `📊_ТЕКУЩИЙ_СТАТУС.md` (текущая задача) |
| `LESSONS_LEARNED.md` | `🤖_АКТИВНЫЙ_АССИСТЕНТ.md` (правила матчинга) |
| Любой код проекта | `🧠_SESSION_CONTEXT.md`, при значимом — `📊_ТЕКУЩИЙ_СТАТУС.md` |
| Новый файл в _ai_workspace | `📚_КАТАЛОГ_ФАЙЛОВ.md` |
| `📈_МЕТРИКИ_ПРОГРЕССА.md` | (отчёт, ничего не обновляет) |
| `📚_КАТАЛОГ_ФАЙЛОВ.md` | (справочник, ничего не обновляет) |
| `🔗_НЕЙРОННЫЕ_СВЯЗИ.md` | (справочник, ничего не обновляет) |

## 🔄 ЖИЗНЕННЫЙ ЦИКЛ ЗАДАЧИ

```
Начало сессии
  ↓
Читаем: МОЗГ_ПРОЕКТА → SESSION_CONTEXT → ТЕКУЩИЙ_СТАТУС → LESSONS_LEARNED
  ↓
Задача
  ↓
Код + тесты + сборка + деплой
  ↓
Обновляем: SESSION_CONTEXT → ТЕКУЩИЙ_СТАТУС → МЕТРИКИ (при значимом прогрессе)
  ↓
Идея появилась? → ЗАДЕЛЫ_ИДЕИ + IDEA_MANAGER процесс
  ↓
Коммит + push + Vercel check
```
