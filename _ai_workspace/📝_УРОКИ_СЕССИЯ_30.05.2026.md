## Что делали
Создали SmartType для шапки сцены с автопереходом на участников.

1. ✅ Подсказки ИНТ./ЭКСТ. при наборе «И»/«Э»
2. ✅ Подсказки локаций (КВАРТИРА, УЛИЦА и т.д.) с фильтрацией
3. ✅ Подсказки времени (ДЕНЬ., НОЧЬ., УТРО., ВЕЧЕР.) с точкой
4. ✅ Автоперенос курсора на новую строку после времени

7. ✅ Tab/Enter — применить, Esc — закрыть, ↑↓ — навигация

## Ключевые решения
- **Тип блока scene_cast** — добавлен для участников сцены
- **Переключение типа** — Tab между элементами шапки
- **Автопереход** — после времени курсор переходит на новую строку для участников
- **SmartType приоритет** — сначала sceneHeaderSuggestions, потом smartType

## Ошибки и как исправляли
1. **Автонумерация мешала вводу** — переписывала номера при каждом изменении. Решение: убрать из handleContentChange, оставить только при создании новой сцены.
2. **Пробел не работал** — autoCompleteSceneHeader заменял текст при каждом изменении. Решение: заменить на SmartType (подсказки без автовставки).
3. **Конфликт подсказок** — smartType и sceneHeaderSuggestions конфликтовали. Решение: sceneHeaderSuggestions приоритетнее.
4. **applySuggestion стирала текст** — неправильно находила последнее слово. Решение: использовать lastIndexOf(' ').
5. **Блок участников создавался внизу** — неправильный индекс. Решение: использовать setBlocks(prevBlocks => ...) для актуального индекса.
