## 📚 БИБЛИЯ ПЕРСОНАЖЕЙ

### Обязательные поля карточки персонажа:
- Имя (капслок)
- Краткая характеристика (2-4 строчки) — тест на понимание
- Архетип, типаж
- Характер, манера поведения
- Взаимоотношения (конфликты, любовная линия, друзья, недруги)
- Мотивация
- Привычки и приметы
- Родственники (только если нужно для сюжета)
- Краткая история, загадочные события

### Фичи:
- Карточки персонажей с полями
- Связи между персонажами (визуальный граф)
- Фото-референсы для кастинга
- Поиск персонажей по характеристикам
- Экспорт/импорт библии

### Чего НЕ нужно:
- Детальное описание внешности (рост, вес, цвет волос)
- Описание одежды и мелочей (видно на экране)

## 🔍 АВТО-РАЗБОР ТЕКСТА (BREAKDOWN)

### Что парсим:
1. **Персонажи** — слова в КАПСЛОКЕ перед диалогами
   - ИВАН → Актёр
   - МАША → Актёр

2. **Локации** — текст после ИНТ./ЭКСТ.
   - «ИНТ. КВАРТИРА ИВАНА — ДЕНЬ» → Локация: КВАРТИРА ИВАНА

3. **Реквизит** — ключевые слова в action-блоках
   - «Иван берёт ПИСТОЛЕТ» → Реквизит: ПИСТОЛЕТ
   - «звонит ТЕЛЕФОН» → Реквизит: ТЕЛЕФОН
   - «садится в МАШИНУ» → Транспорт: МАШИНА

### Категории breakdown:
- Cast (актёры)
- Extras (массовка)
- Props (реквизит)
- Costumes (костюмы)
- Locations (локации)
- Vehicles (транспорт)
- SFX (спецэффекты)
- Stunts (трюки)
- VFX (визуальные эффекты)
- Notes (заметки)

## 📊 СТАТИСТИКА И АНАЛИТИКА

### Метрики:
- Общий хронометраж
- Количество сцен (всего / по локациям / по персонажам)
- Страницы / Слова / Символы
- Активность персонажей (сколько сцен с каждым)
- Динамика сцен (хронометраж по сценам)
- Баланс ИНТ/ЭКСТ
- Распределение по времени суток (ДЕНЬ / НОЧЬ / УТРО / ВЕЧЕР)
- Соотношение диалог/действие

### Алерты:
- ⚠️ Персонаж пропал на N страницах
- ⚠️ Сцена слишком длинная (рекомендуется 2-3 минуты)
- ⚠️ 3 сцены подряд только диалог — добавить действие?
- ⚠️ Время изменилось без перехода (ночь → день)
- ⚠️ Локация изменилась без CUT TO

### Графики:
- График активности персонажей по сценам
- Линейный график хронометража по сценам
- Круговая диаграмма ИНТ/ЭКСТ
- Столбчатая диаграмма времени суток

## 🤖 SMART ASSISTANT (ПОМОЩНИК)

### SmartType (автодополнение):
- При вводе «ИВ...» — подсказка «ИВАН (введён в сцене 1)»
- При вводе локации — подсказка из уже использованных
- Tab для автодополнения
- История персонажей — подсказки из справочника проекта
- Подсказки локаций из уже использованных в проекте

### Контекстные подсказки:
- При создании сцены 10: «В сцене 5 Иван получил пистолет. Добавить сюда?»
- При вводе диалога: «Иван не появлялся 8 страниц. Напомнить читателю кто он?»

### Проверка непрерывности:
- «В сцене 3 было ночь, а здесь день. Указать прошло время?»
- «Локация изменилась без перехода. Добавить CUT TO?»

### Голосовой набор (опционально):
- Говоришь — текст превращается в форматированный сценарий
- «Сцена первая, интерьер, квартира Ивана, день...» → 1. ИНТ. КВАРТИРА ИВАНА — ДЕНЬ

## 🎨 КАРТОЧКИ СЦЕН (STORYBOARD)

### Функционал:
- Визуальная доска с карточками сцен
- Drag & Drop — перетаскивание для изменения порядка
- Раскраска по актам / цветам / локациям
- Группировка в колонки (по актам, локациям, персонажам)
- Синхронизация с текстом — изменение в карточках меняет порядок в сценарии
- Размеры карточек: компактная / развёрнутая (с синопсисом)
- Печать карточек на бумагу (форматы A4, Letter)
- Двойной клик → переход к сцене в тексте

## 📐 ФОРМАТИРОВАНИЕ

### Авто-форматирование (по умолчанию):
| Что пишет пользователь | Распознаётся как |
|------------------------|------------------|
| `ИНТ.` / `ЭКСТ.` / `ИНТ./ЭКСТ.` | Заголовок сцены |
| `НАПЛЫВ:` / `СМЕНА ПЛАНА:` | Переход |
| ВСЕ ЗАГЛАВНЫЕ (2+ слова) | Имя персонажа |
| Обычный текст после имени | Диалог |
| Текст в скобках `(взволнованно)` | Ремарка в диалоге |
| Текст без заглавных | Описание действия (ремарка) |

### Ручное управление (Tab/Enter):
- **Tab** — переключить тип текущего абзаца циклически
- **Enter** в конце диалога → автоматически переход к ремарке
- **Ctrl+1..6** — быстрое переключение типа абзаца по номеру

### Форматы:
- Голливудский (WGA стандарт)
- Российский (КИТ Сценарист стандарт)
- Пользовательский

### Шрифты:
- Courier New (по умолчанию)
- Courier Prime (опционально)
- Другой (моноширинный)

## ⏱️ ХРОНОМЕТРАЖ

### Системы расчёта:
- Постраничный — 1 страница = 1 минута (стандарт)
- Посимвольный — N символов = 1 секунда
- Гибкий — комбинация методов
- Ручной — пользователь задаёт время сцены

### Жанровые коэффициенты:
- Мюзиклы — 0.9 (54 секунды на страницу)
- Военные — 0.99 (59.4 секунды)
- Драма — ~1.0 (60 секунд)
- Комедия — 1.15 (52 секунды)

### Реалистичный расчёт:
- По умолчанию: 1 страница = 55 секунд (исследование Stephen Follows)
- Пользователь может выбрать коэффициент по жанру

## 🌍 РАЗДЕЛ "РАЗРАБОТКА"

### Базовые элементы:
1. **Персонажи**
   - Имя, возраст, описание внешности
   - Биография, цели, арки
   - Материалы (фото, референсы, актёры)
   - Связи с другими персонажами (граф связей)

2. **Локации**
   - Название, тип (интерьер/экстерьер)
   - Описание, особенности
   - Материалы (фото, планировки)
   - Реальные адреса (для съёмок)

3. **Мир**
   - Лонглайн (1-2 страницы)
   - Синопсис (5-10 страниц)
   - Тритмент
   - История мира

### Дополнительные фичи:
4. **Хронология / Таймлайн**
   - Последовательность событий вне сценария
   - Временные промежутки между сценами
   - Параллельные линии (для сериалов)

5. **Темы и мотивы**
   - Центральная тема сценария
   - Визуальные мотивы
   - Музыкальные темы (для референсов)

6. **Библиография / Референсы**
   - Похожие фильмы/сериалы
   - Книги, статьи, исследования
   - Ссылки на реальные события

7. **Глоссарий**
   - Термины мира сценария
   - Профессиональный жаргон
   - Имена собственные

## 🎯 УНИКАЛЬНЫЕ ФИШКИ КИНОПЛАН

### Нет у конкурентов:
1. **Сценарный дашборд в реальном времени**
   - Пока пишешь — видишь метрики
   - Цветовая индикация: зелёный (хорошо), жёлтый (внимание), красный (проблема)

2. **Сравнение версий**
   - Черновик 1 vs Черновик 2: что изменилось
   - «+2 новых персонажа, -1 локация, хронометраж +5 минут»

3. **Рекомендации от AI**
   - «У вас 12 персонажей — много для короткометражки, рекомендуется 3-5»
   - «Соотношение диалог/действие 70/30 — для триллера лучше 50/50»

4. **Интеграция с кастингом**
   - Нажал на актёра → видишь все его сцены
   - Кнопка «Создать выборку для актёра»

5. **Единая экосистема**
   - Сценарист пишет → 2-й режиссёр видит изменения → Breakdown автоматически обновляется
   - Сцены из сценария → Stripboard → Вызывные листы

## 🔗 ИНТЕГРАЦИЯ С ДРУГИМИ МОДУЛЯМИ

### Сценарий → Кастинг
- Персонажи из сценария → автоматическое создание карточек персонажей
- Активность персонажей → расчёт занятости актёров (DOOD Report)
- Изменения в сценарии → уведомление кастинг-директора

### Сценарий → Локации
- Слаглоны сцен (ИНТ. КВАРТИРА МАРИНЫ) → автоматическое создание ScriptLocation
- Количество сцен на локацию → приоритет для скаутинга
- Изменения в сценарии → уведомление о новых локациях

### Сценарий → Расписание (Stripboard)
- Сцены из сценария → источник для планирования
- Хронометраж сцен → расчёт времени съёмочного дня
- INT/EXT, День/Ночь → тип съёмочного дня
- Персонажи в сцене → DOOD Report

### Сценарий → Вызывные
- Сцены дня → автоматическое заполнение вызывного

## 🎬 КОНЦЕПЦИЯ "ПРОГРАММА В ПРОГРАММЕ"

### Философия
Модуль сценария должен быть самодостаточным приложением внутри КиноПлана. Сценарист переходит из Final Draft или КИТ Сценарист и получает знакомый UI/UX.

### Связка: Сценарист ↔ Второй режиссёр
- Список всех драфтов (Черновик 1, Черновик 2, Съёмочный)
- Diff между драфтами (+3 сцены, -1 сцена, ~8 сцен)
- Влияние на ресурсы (+2 персонажа, +1 локация, +150,000 ₽)
- Выбор активной версии для продакшена
- Авто-обновление Breakdown, Stripboard, Вызывных при смене версии

### Структура версионности
```typescript
interface ScriptDraft {

  scriptId: string
  version: string
  name: string
  createdAt: string

  isActive: boolean

}

  id: string
  type: 'added' | 'removed' | 'modified'
  category: 'scene' | 'character' | 'location' | 'dialogue'
  description: string
  impact?: {
    budget?: number

  }
```
