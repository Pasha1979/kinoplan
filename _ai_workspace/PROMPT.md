## 1. ИДЕНТИЧНОСТЬ ПРОЕКТА

**Название:** КиноПлан
**Тип:** Desktop (Win/macOS/Linux) + Mobile (iOS/Android) приложение
**Аудитория:** Российские киноработники (2-й режиссёр, продюсер, скрипт-супервайзер, кастинг-директор и др.)
**Девиз:** «Профессиональная мощь в одном приложении. Ваши данные — на вашем устройстве.»

---

## 2. ФИЛОСОФИЯ И ОГРАНИЧЕНИЯ

**Архитектурный принцип:** Local-First / Offline-First
- Все данные хранятся локально на устройстве пользователя
- Интернет используется ТОЛЬКО опционально (синхронизация, рассылка, погода)
- Приложение обязано работать полностью оффлайн

**Строго запрещено предлагать:**
- ❌ Серверную / облачную архитектуру по умолчанию
- ❌ Модуль бюджетирования или финансовые расчёты
- ❌ Публичную базу актёров или каталог фрилансеров
- ❌ Обязательную интернет-зависимость
- ❌ Интеграции с 1С, Контур, СБИС, Госуслугами, AWS, GCP
- ❌ Термины и форматы, несовместимые с российскими стандартами

## 3. ТЕХНОЛОГИЧЕСКИЙ СТЕК (СОГЛАСОВАН)

| Компонент | Технология | Примечание |
|---|---|---|
| Frontend | React + TypeScript | Единая кодовая база |
| Сборка | Vite | Быстрая разработка |
| Стили | Tailwind CSS + shadcn/ui | Современный UI |
| Состояние | Zustand | Легковесно, по модулям |
| Роутинг | react-router-dom v6 | Два уровня маршрутов |
| Desktop-оболочка | Electron | Windows / macOS / Linux |
| Mobile-оболочка | Capacitor | iOS / Android |
| Локальная БД | SQLite (better-sqlite3 / @capacitor-community/sqlite) | Десктоп + мобильные |
| Медиа-хранение | Файловая система устройства + метаданные в БД | Видео, фото, PDF |
| Шифрование | AES-256 (опционально) | На уровне проекта |
| Синхронизация | WebDAV (Яндекс.Диск, VK Cloud), P2P Wi-Fi | Опционально |

## 7. ПРАВИЛА ДЛЯ AI ПРИ НАПИСАНИИ КОДА

1. **Local-First check**: перед любым решением проверять — работает ли оффлайн?
2. **IPC-принцип**: React никогда не обращается к SQLite напрямую — только через IPC
3. **Модульность**: каждый модуль — изолированная страница со своим стором и репозиторием
4. **Миграции**: любое изменение схемы БД — через файл миграции, не вручную
5. **Русский язык**: все UI-тексты, ошибки, подсказки — только на русском
6. **Типографика**: учитывать кириллические стандарты (тире, кавычки-ёлочки и т.д.)
7. **Комментарии в коде**: указывать локальное хранение, оффлайн-сценарии, шифрование
