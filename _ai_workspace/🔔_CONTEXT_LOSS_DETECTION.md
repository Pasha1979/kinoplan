# 🔔 CONTEXT LOSS DETECTION — Автоматическое определение потери контекста

> **Назначение:** Автоматическое определение потери контекста и восстановление

---

## 🧠 КАК ОПРЕДЕЛИТЬ ПОТЕРЮ КОНТЕКСТА

### ПРИЗНАКИ ПОТЕРИ КОНТЕКСТА:
1. **Пропали сообщения из истории** — видно только последние сообщения
2. **Нет памяти о предыдущих действиях** — не помню что делал до
3. **Нет ссылок на файлы** — не знаю какие файлы редактировал
4. **Нет информации о коммитах** — не помню хэш последнего коммита
5. **Нет информации о деплоях** — не помню статус Vercel

### ПРОВЕРКА ПРИ НАЧАЛЕ СЕССИИ:
```markdown
Автоматически выполни:
1. Прочитай 🧠_SESSION_CONTEXT.md
2. Сравни дату сессии с текущей датой
3. Если дата старая (>1 часа) → контекст потерян
4. Если нет информации о последних действиях → контекст потерян
5. Если есть разрыв в истории → контекст потерян
```

---

## 🔄 АВТОМАТИЧЕСКОЕ ВОССТАНОВЛЕНИЕ

### АЛГОРИТМ ВОССТАНОВЛЕНИЯ:
1. **Прочитать 🧠_SESSION_CONTEXT.md**
2. **Прочитать .env** → получить токен Vercel
3. **Прочитать обязательные файлы:**
   - 🧠_МОЗГ_ПРОЕКТА.md
   - 📊_ТЕКУЩИЙ_СТАТУС.md
   - LESSONS_LEARNED.md
   - 🤖_АКТИВНЫЙ_АССИСТЕНТ.md
4. **Восстановить контекст:**
   - Текущая задача
   - Что сделано
   - Следующие шаги
   - Последний коммит
   - Статус Vercel
5. **Сообщить пользователю:** "Контекст восстановлен из 🧠_SESSION_CONTEXT.md"

---

## ⚠️ ЕСЛИ КОНТЕКСТ НЕЛЬЗЯ ВОССТАНОВИТЬ

### СИТУАЦИИ:
- 🧠_SESSION_CONTEXT.md не существует
- 🧠_SESSION_CONTEXT.md пустой
- 🧠_SESSION_CONTEXT.md старый (>7 дней)

1. Сообщить пользователю: "Контекст потерян и не может быть восстановлен"
