# 🤖 AI-МОЗГ — Автономная работа с _ai_workspace

## ⚡ ТРИГГЕРЫ ДЛЯ АКТИВАЦИИ (проверять каждые 10 минут работы)

### 🔍 Анализ контекста
- [ ] Прочитать CURRENT_STEP.md — что сейчас делаем?
- [ ] Прочитать CURRENT_STATUS.md — какой прогресс?
- [ ] Проверить LESSONS_LEARNED.md — какие ошибки были?

### 🎯 Проверка плана
- [ ] Текущий шаг логичен?
- [ ] Нет ли пропущенных подзадач?
- [ ] Следующий шаг понятен?
- [ ] Есть ли блокеры?

### 🏗️ Проверка архитектуры
- [ ] Изменения соответствуют архитектуре?
- [ ] Нет ли нарушения принципов (Local-First, Offline-First)?
- [ ] Создаю ли я технический долг?
- [ ] Нужно ли обновить архитектурную документацию?

### 💡 Генерация идей
- [ ] Можно ли улучшить текущую реализацию?
- [ ] Есть ли риски, о которых не сказал?
- [ ] Можно ли добавить "фишку" из конкурентов?
- [ ] Нужны ли дополнительные проверки/тесты?


### После действия:
```
✅ РЕЗУЛЬТАТ: [что сделал]
📝 ДОКУМЕНТАЦИЯ: [что обновил в _ai_workspace]
🎯 СЛЕДУЮЩИЙ ШАГ: [что дальше]
```

## 🚨 ОБЯЗАТЕЛЬНЫЕ ДЕЙСТВИЯ (без напоминаний!)

### Каждые 30 минут работы:
1. Сохранить прогресс в _ai_workspace
2. Проверить, не забыл ли документировать
3. Задать пользователю вопрос, если есть неясности

### После каждого коммита:
1. Обновить CURRENT_STATUS.md
2. Добавить урок, если было исправление ошибки
3. Проверить логичность следующего шага

### При обнаружении проблемы:
1. НЕ чинить сразу — задокументировать
2. Предложить 2-3 варианта решения
3. Обсудить с пользователем ПЕРЕД фиксом

## 💬 ВОПРОСЫ ПОЛЬЗОВАТЕЛЮ (задавать самостоятельно!)

### Когда неясно:
- "Я вижу два варианта: A и B. Какой предпочтительнее?"
- "Это может повлиять на X. Учитывать ли это сейчас?"
- "Есть ли приоритет: скорость или качество?"

### Когда вижу возможность улучшения:
- "Можно добавить фичу из Filmtoolz/Movie Magic — интересно?"
- "Вижу паттерн, который можно улучшить. Обсудить?"
- "Это место можно сделать удобнее. Показать варианты?"

### Когда вижу риск:
- "⚠️ Это изменение может сломать X. Как быть?"
- "Обнаружил потенциальную проблему с архитектурой. Обсудить?"
