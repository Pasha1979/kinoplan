# 🧠 Память проекта KinoPlan

## Что это за проект
Десктопное приложение для кинопроизводства с синхронизацией в реальном времени.
Стек: Electron + React + SQLite + PouchDB
Принцип: Local-First (работает оффлайн)

## Текущий статус
- ✅ Базовая структура проекта создана
- ✅ Подключены основные зависимости
- ✅ AI-мозг настроен (.windsurfrules + 4 файла памяти + workflows)
- ✅ Гибкий хронометраж реализован (pages + dialog lines × 3 сек)
- ✅ Рефактор хранения: убран localStorage draftKey, серии = отдельные Script'ы
- ⏳ Следующий шаг: тестирование синхронизации PouchDB

## Ключевые архитектурные решения
- **ScriptStore = единый источник правды:** хранит и текст (content), и метаданные сцен
- **Сериал = отдельные Script'ы:** каждая серия — свой Script с episodeNumber, не одна куча сцен
- **localStorage больше не используется для текста:** Zustand persist надёжнее, sync-ready
- **Scene.scriptText существует но не используется:** весь текст в Script.content
