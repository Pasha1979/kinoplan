# Workflow: Старт новой сессии

При вызове этого workflow выполни:

1. Прочитай в строгом порядке:
   - `_ai_workspace/BRAIN.md`
   - `_ai_workspace/CURRENT_TASK.md`
   - `_ai_workspace/LESSONS.md`
   - `_ai_workspace/ARCHITECTURE.md`

2. Кратко (3-5 предложений) сообщи пользователю:
   - Что это за проект
   - На каком этапе мы сейчас
   - Какая задача стоит перед нами
   - Какие уроки из прошлого нельзя забывать

3. Спроси пользователя: "С чего начнём? Продолжаем текущую задачу или ставим новую?"

4. Дождись ответа и приступай к работе
