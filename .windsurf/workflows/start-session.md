# Workflow: Старт новой сессии

При вызове этого workflow выполни:

1. Прочитай в строгом порядке:
   - `_ai_workspace/🧠_МОЗГ_ПРОЕКТА.md`
   - `_ai_workspace/📊_ТЕКУЩИЙ_СТАТУС.md`
   - `_ai_workspace/LESSONS_LEARNED.md`
   - `_ai_workspace/ARCHITECTURE_GUARDIAN.md`
   - `_ai_workspace/🤖_АКТИВНЫЙ_АССИСТЕНТ.md`

2. Запусти Lesson Matching:
   - Проанализируй контекст предстоящей работы
   - Найди релевантные уроки в LESSONS_LEARNED.md
   - Предложи 1-3 релевантных урока

3. Кратко (3-5 предложений) сообщи пользователю:
   - Что это за проект
   - На каком этапе мы сейчас
   - Какая задача стоит перед нами
   - Какие уроки из прошлого нельзя забывать

4. Спроси пользователя: "С чего начнём? Продолжаем текущую задачу или ставим новую?"

5. Дождись ответа и приступай к работе
