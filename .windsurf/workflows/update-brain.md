# Workflow: Обновление AI-мозга

При вызове этого workflow выполни:

1. Прочитай все файлы в `_ai_workspace/`:
   - BRAIN.md
   - CURRENT_TASK.md
   - LESSONS.md
   - ARCHITECTURE.md

2. Проанализируй что было сделано в текущей сессии (по истории чата)

3. Обнови файлы:
   - **CURRENT_TASK.md**: отметь выполненное, напиши что осталось, добавь следующий шаг
   - **LESSONS.md**: если были ошибки или неочевидные моменты, добавь урок
   - **ARCHITECTURE.md**: если изменились архитектурные решения, обнови
   - **BRAIN.md**: если произошли важные события, добавь их с датой

4. Сообщи пользователю что мозг обновлён и кратко резюмируй изменения

5. Подтверди что все файлы сохранены

6. **Обязательно** выполни коммит и пуш:
   - `git add -A`
   - `git commit -m "feat/fix: <краткое описание сессии>"`
   - `git push origin main`
   - Сообщи пользователю хэш коммита и что изменения на GitHub
